Интеграция переводчика

Этот экран должен жить в системных настройках админки. Он хранит ключи провайдеров и управляет режимом перевода для экспертного чата.

DeepL

Основной провайдер для перевода сообщений эксперта

Google

Резервный провайдер Cloud Translation

Amazon

Резервный провайдер Amazon Translate

Настройки переводчика

Макет собран на тех же AdminLTE-компонентах, что и текущая админка: `callout`, `small-box`, `box`, `form-group`, стандартные `btn`.

Общий режим

Управляет логикой перевода в чате эксперта и выбором основного провайдера.

DeepL

Рекомендуемый основной провайдер с наивысшим приоритетом.

Google Cloud Translation

Держим выключенным, пока не заполнены и не проверены ключи.

Amazon Translate

AWS-ключи хранятся только для сценария интеграции переводчика.

Рекомендованное размещение в меню: `Система -> Переводчик`. Не смешивать с обычными контент-настройками и не прятать внутрь страницы чата.
