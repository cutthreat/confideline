## Важно

Это не юридическое заключение и не финальная редакция для публикации. Документы нужно проверить юристом по выбранной юрисдикции ЕС, особенно:

- возрастной порог;
- право отказа/withdrawal для цифровых услуг;
- модель кредитов, подписок и автоматического продления;
- применимое право и подсудность;
- статус консультантов;
- необходимость DPO/представителя/надзорного органа;
- налоговые и платежные формулировки.
