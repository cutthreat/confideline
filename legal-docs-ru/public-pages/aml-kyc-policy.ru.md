# AML / KYC Policy Confideline.com

Статус: проект для юридической и платежной проверки.

## 1. Назначение

Эта политика описывает меры проверки личности, выплат и предотвращения злоупотреблений, применимые к консультантам, партнерам и иным получателям выплат.

## 2. Когда может требоваться KYC

KYC может требоваться:

- перед первой выплатой консультанту;
- при достижении payout threshold;
- при подозрении на fraud;
- по требованию платежного провайдера;
- по требованию закона.

## 3. Какие данные могут запрашиваться

- имя и фамилия;
- дата рождения;
- адрес;
- документ личности;
- налоговая информация;
- payout account;
- подтверждение статуса независимого подрядчика;
- дополнительные данные, если требует провайдер.

## 4. Запрещенные действия

- stolen cards;
- money mule activity;
- вывод средств третьим лицам;
- обход санкций;
- chargeback abuse;
- фейковые консультации для вывода средств.

## 5. Проверки

Confideline.com может приостанавливать выплаты на время проверки fraud/KYC/chargeback.
