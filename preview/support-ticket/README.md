# Support ticket interactive preview

Public, static copy of the local support-ticket prototype, with internal discussion.

Open `support-ticket-chat-final.html`. The queue is `support-ticket-queue-final.html`.
Actions use local demo results. API connections and form submissions are disabled.
Messages and draft changes are not sent to ConfideLine. No backend, account or credentials are included.

Bootstrap, AdminLTE, jQuery, Font Awesome, SlimScroll and Fancybox are the existing locally bundled vendor assets. Existing prototype image URLs remain external image resources.
