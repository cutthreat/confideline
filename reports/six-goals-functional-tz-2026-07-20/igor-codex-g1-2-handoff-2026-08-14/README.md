# G1.2 — комплект для Игоря и Codex

Эта папка содержит единый пакет для интеграции административного чата по ролям.
Все файлы зафиксированы одним снимком и передаются вместе.

## Порядок чтения

1. `tz-g1-2-for-igor.html` — основной документ для Игоря.
2. `tz-g1-2-for-igor.docx` — версия для вычитки и комментариев.
3. `G1_ARCHIVE_HTML_CONTRACT_AUDIT_2026-08-14.md` — сверка каждой области HTML-макета с контрактами.
4. `G1_CONTEXT_CANONICAL_RECONCILIATION_2026-08-14.md` — порядок источников, канонические решения и замок текущей интеграции.
5. `codex-context-g1-2-role-chat.md` — технический контекст для Codex.
6. `codex-context-g1-2-actions-templates-answers-ru.md` — точные правила кнопок, шаблонов, языков и ссылок.
7. `codex-context-badge-resolver-ru.md` и `badge-resolver-rules-ru.csv` — каноника бейджей.
8. `admin-chat-stage1-20260804-handoff.rar` — исходный HTML/JS/CSS и контракты макета.

## Приоритет источников

Прямые решения Product Owner → каноническая сверка → контракты архива → ТЗ → Codex-контекст → производные HTML/DOCX.

Demo-значения, статические IDs и разделы `Open Production Decisions` не являются готовой backend-логикой.
Отложенные кнопки и функции должны оставаться disabled/visual-only до отдельного решения Product Owner.
