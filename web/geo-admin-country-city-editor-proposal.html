Доступные переменные

Переменная Что подставляется Где использовать
{{siteName}} Название проекта. Тексты, Meta Title, Meta Description
{{geoName}} Название текущей страницы: страна или город. H1, H2, FAQ, SEO
{{countryName}} Название страны текущей страницы. Страницы стран и городов
{{cityName}} Название города текущей страницы. Страницы городов
{{whatWeOfferBlock}} Единый блок “Что предлагаем”. Html Description
{{geoServiceListBlock}} Единый список услуг для гео-страниц. Html Description
{{informationalDisclaimerBlock}} Единый информационный дисклеймер. Низ Html Description, FAQ
{{languageName}} Текущий язык страницы. Служебные SEO-шаблоны
