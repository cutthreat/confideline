Кто что должен сделать дальше

Это очередь действий, которая переводит подготовленные PM-пакеты в проверяемый runtime proof. Главный фокус сейчас — один тестовый заказ без реальных денег и писем, а не расширение списка функций.

Главный принцип

Сначала доказываем рабочий маршрут платной консультации. После этого пересчитываем готовность, а не спорим заранее о рекламе, LTV и масштабировании.

Что не делаем

Не меняем production, не запускаем реальные платежи, не отправляем клиентам письма, не публикуем финальные legal-документы без решений основателя.

Распределение по людям

PM / Codex

Делает сам: proof-база, Blue Panel, задачи, регламент, школа, сценарии QA, публикация результатов, синхронизация Trello.

Игорь

Первый фокус: test order lifecycle: order, question, service_session, assignment, chat, events, support.

QA / тестировщик

Первый фокус: пройти QA-пакет test order, снять скрины, вернуть PASS/WARN/STOP и задачи Игорю.

Ксения

Роль ревизора: проверить понятность школы, регламента и примеров ответов глазами эксперта-новичка.

Антон

Дизайн: правки по офферу, trust, CTA, checkout, chat, support и связи экранов с backend.

Основатель

Решает: legal/payment/refund/geography, выплаты, и момент первого рекламного теста после proof.
