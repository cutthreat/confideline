Рекламу включаем только после доказанного сервиса

Маркетинг можно готовить сейчас: оффер, креативы, UTM, email, organic/PR, daily report. Но первый платный трафик нельзя запускать, пока сервис не доказал заказ, эксперта, уведомления, support, аналитику покупки, документы и QA.

PM-решение

Первый рекламный тест должен проверять рынок и оффер, а не искать поломки продукта. До QA PASS/WARN разрешена только подготовка материалов без внешнего запуска.

Стартовая модель

Честная разовая текстовая консультация. Без скрытой подписки, без гарантированных предсказаний, без давления на страхи и без обещания окончательного решения личной проблемы.

Текущий вывод: CAC/LTV сейчас нельзя считать фактами. Их можно моделировать, но не использовать для решения о масштабировании до purchase analytics proof.

Что PM может делать автономно сейчас

Можно делать без ожидания

Оффер, тексты LP/checkout/email, UTM/event schema, daily report, CAC/LTV calculator, креативный policy-checklist, organic/PR/UGC shortlist, retention drafts, suppression rules.

Нельзя делать автономно

Запускать рекламу, публиковать внешние материалы, отправлять реальные письма, принимать реальные платежи, утверждать legal/payment решения, считать CAC/LTV фактами без purchase proof.
