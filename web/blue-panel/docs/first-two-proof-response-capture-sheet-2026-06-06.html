Приемка первых ответов без самообмана

Эта страница нужна на момент, когда Игорь или Ксения ответят. PM не ставит “принято” по общим словам. Принятие возможно только по обязательным полям, ID, скринам, route, no-charge/no-send proof и явному verdict.

R01 не полученR02 не полученQA закрыткритерии приемки готовы

Главное правило

Inbox = ответ пришел. Приемка = PM проверил поля. Светофор меняется только после accepted.

Что не принимаем

“Все готово”, один скрин без ID, устное обещание, route без order_id, ответ эксперта вне заказа, отсутствие no-send/no-charge proof.

Что открывает QA-ready

Только accepted R01 + accepted R02. Partial не открывает QA.
