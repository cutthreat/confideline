Рабочий день PM

1Утро: отправка и статус R01/R02Проверить, отправлены ли два сообщения. Если нет — отправить. Если отправлены — смотреть, кто не ответил.2День: входящие ответыПроверить inbox. Если ответ пришел, не менять статус, а перенести в лист приема.3День: решение PMПоставить по R01/R02: принято, вернуть или блокер. Слабый ответ не меняет светофор.4Вечер: QA-readyЕсли R01 и R02 приняты, открыть QA-ready. Если нет — QA остается закрыт.5Вечер: светофорМенять только те слои, по которым есть принятое доказательство.
Главный фокус: daily cycle сейчас подчинен не “делать больше документов”, а получить и принять два факта: safe order и E01 для QA.
