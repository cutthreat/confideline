Лист фиксации фактов контрольного заказа

Это рабочий лист для PM, Игоря и QA. Он превращает первый тестовый заказ в доказательство: где order id, какой экран снят, какой лог приложен, кто подтвердил, что осталось красным.

пока не заполненоготово для QA-прохода после gateединый proof-формат
PM-решение

Без этого листа контрольный заказ легко превратится в набор разрозненных скринов. Лист задает один формат: факт, ссылка на доказательство, владелец, статус и следующий шаг.

Граница безопасности

Лист не запускает реальные платежи, письма или внешнюю рекламу. Он только фиксирует доказательства безопасного тестового маршрута.

12фактов нужно собрать для смены статуса
0фактов заполнено сейчас
3участника: PM, Игорь, QA
1итог: PASS / WARN / STOP
Как использовать: строка считается зеленой только когда есть конкретная ссылка на скрин, лог, отчет, admin route или опубликованный QA-proof. Слова “работает” без evidence не принимаются.
