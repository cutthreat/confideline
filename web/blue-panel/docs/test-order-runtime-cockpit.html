Маршрут выполнения

1. ПодготовкаФиксируем тестового клиента, эксперта/агента, услугу, цену, язык, no-send режим и rollback-правила.
2. ЗаказПроходим offer → checkout → test order без реального списания.
3. КонсультацияСвязываем вопрос клиента, service session, назначение исполнителя и ответ.
4. КонтрольПроверяем admin visibility, события, no-send уведомления, support/problem state и начисление.
5. QA-решениеЗаполняем отчет со скринами и итогом PASS/WARN/STOP.
Критерий успеха: один тестовый заказ должен быть доказан скринами/логами с обеих сторон: клиент, исполнитель, админка, события, support и итоговый QA-отчет.
