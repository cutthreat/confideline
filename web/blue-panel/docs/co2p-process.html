Процесс работы от идеи до внедрения

Стандарт, по которому мы с тобой как PM готовим задачи, передаем их команде и контролируем результат.

Идея → PM-разбор → доказательства → интерактивный макет/ТЗ → согласование → Trello → co2p-пакет для программиста → внедрение → тестировщик → приемка → ежедневный контроль.

PM не передает идею вслепую

Сначала собирается контекст, проверяются факты и формируется понятное решение.

Заказчик должен увидеть и покликать

Если есть экран или сценарий, делается интерактивный HTML-макет.

Программист получает co2p-пакет

Не только текст, а макет, логику, backend-связи, роли, данные и критерии приемки.

Тестировщик получает ожидаемый результат

Сценарии, роли, тестовые данные, что считается ошибкой и какие скриншоты нужны.
