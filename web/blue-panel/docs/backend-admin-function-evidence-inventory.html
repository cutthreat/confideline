Реестр backend/admin функций и доказательств

Confideline — это база универсальной P2P-платформы, но запуск Nebula доказывается не наличием отдельных моделей, а связанной цепочкой: заказ, вопрос, консультация, назначение, рабочее место, ответ, события, support и отчет.

1 зеленый источник6 желтых foundation-зон9 красных runtime-блокеров0 контрольных заказов
PM-вывод

Backend-база есть, но MVP нельзя считать готовым: красными остаются test order, question binding, service session, assignment, workspace, delivery, no-send, support, analytics и test isolation.

Как использовать

Игорю — как перечень AC и proof. QA — как маршрут скриншотов. PM — как строгий фильтр: “бек есть” не равно “функция готова для клиента”.

Правило: существующий dating/user/chat/order функционал считается платформенной базой. Для Nebula зеленый статус появляется только когда эта база связана с платной консультацией и подтверждена test order evidence.
