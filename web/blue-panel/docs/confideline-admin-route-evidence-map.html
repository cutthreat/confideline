PM-вывод

Confideline admin уже покрывает много универсальных функций платформы. Для Nebula не нужно начинать админку с нуля. Но нельзя считать MVP готовым, пока не доказана единая paid consultation операционная карточка: заказ, вопрос, назначение, эксперт/агент, чат, ответ, события, поддержка и итог.

Как использовать карту

Для когоЧто делатьЧто не делать
PM / АлексейИспользовать как доказательство, что backend/admin база есть, но нужен service_session runtime.Не говорить Заказчику “админка готова”, пока нет test order QA.
ИгорьБрать существующие Order/Message/User/Notification/Report слои и связывать их в paid consultation.Не писать отдельную систему вслепую без связи с текущими контроллерами.
QAПроверять админку на одном test order: заказ, вопрос, эксперт, чат, support, события.Не проверять страницы админки абстрактно без бизнес-сценария.
