Первый трафик запускается только как ограниченный тест после QA PASS

Маркетинг не может быть отдельным от операционки: 5 экспертов имеют ограниченную емкость, support должен выдержать первые проблемы, а экономика должна иметь stop-сигналы до масштабирования.

PM-решение

Маркетинг остается красным для запуска paid traffic. Подготовку офферов, UTM, отчетов и CAC/LTV можно делать сейчас, но покупать трафик нельзя до runtime QA PASS и допуска первых 5 экспертов.

Что считается первым запуском

Не масштабирование, а управляемый тест с дневным лимитом заявок, ручным контролем качества, daily report и правом остановки.

Минимальная формула первого лимита

Пакет допуска первых 5 экспертовEP01-EP10, слоты E01-E05, роль Ксении, scorecard, SLA, capacity и связь с test order. Preflight первого трафикаЧто должно быть готово до первого рекламного дня и какие gate запрещают запуск. Емкость 5 экспертовДо трафика нужно знать доступные часы, среднее время ответа и буфер на support.Приемка capacityКакие данные по E01-E05 превращаются в дневной лимит трафика. CAC/LTV preflightПервый тест не масштабируется без допустимого CAC и gross margin logic. Daily reportКаждый день теста: трафик, деньги, заказы, SLA, качество, support, решение. Runtime proofТрафик запрещен до PASS/WARN по контрольному заказу.
STOP: paid traffic нельзя включать сейчас. Разрешена только подготовка кампаний, UTM, отчетов, офферов и лендингов без внешней публикации/покупки трафика.
Первый допуск после PASS: маленький дневной лимит, ручная модерация каждого заказа, контроль SLA и support, ежедневный отчет, запрет масштабирования без итогового решения.
