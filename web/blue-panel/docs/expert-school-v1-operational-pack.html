Операционный пакет школы экспертов v1

Практический пакет для подготовки первых 5 экспертов до платных консультаций. Он не заменяет будущую полноценную учебную панель, но уже задает маршрут: что эксперт должен пройти, что написать, кто проверяет и по каким критериям его допускают к работе.

Решение PM

Школа v1 запускается как ручной процесс: документы + тест + практический ответ + ручной допуск. Это быстрее и безопаснее, чем ждать полноценную LMS. Закрытые уроки AskNebula/PbExpert остаются важным источником, но пока они не извлечены, школа v1 опирается на найденные источники, регламент v1, рубрику качества и рабочие требования платформы.

пакет v1 собран нужны файлы уроков нет журнала 5 экспертов Ксения = ревизор

Маршрут обучения

1. Вводчто продаем, кто клиент, роль эксперта
2. Правиласроки, запреты, работа внутри платформы
3. Ответструктура, персональность, безопасность
4. Чатдиалог, эмоция, уточнения, follow-up
5. Практика2 тестовых ответа по кейсам
6. ПроверкаPM + Ксения как ревизор понятности
7. Допускадмин вручную включает в работу

Тест допуска

Блок 1. Правила платформы

Роли, сроки, запрет внешних контактов, что делать при просрочке.

Блок 2. Запреты

Гарантии, медицинские/юридические/финансовые советы, давление страхом, грубость.

Блок 3. Качество ответа

Структура, персонализация, эмпатия, вывод, следующий шаг.

Блок 4. Практика

Два ответа по кейсам клиента с оценкой по рубрике.

Задача Ксении

Материал: регламент v1, программа школы v1, тест допуска, один практический кейс.

Роль: пройти как эксперт-новичок и проверить, можно ли по этому реально начать работу.

Шаги: прочитать материалы, пройти тестовый кейс, отметить непонятные места, оценить реалистичность, дать вердикт.

Результат: список конкретных замечаний с привязкой к месту, оценка понятности 1-5, вердикт “готово / мелкие правки / заблокировано”.
