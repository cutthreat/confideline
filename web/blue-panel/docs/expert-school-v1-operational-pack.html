Критерии готовности школы

должно быть

Эксперт понимает работу без устных объяснений

  • есть правила ответа;
  • есть примеры и антипримеры;
  • есть тест;
  • есть практическое задание;
  • есть понятный статус допуска.
нельзя запускать

Если нет контроля качества

Платный трафик нельзя вести, если первые эксперты не прошли тест, не дали пробные ответы и не подтверждены PM вручную.

Школа не равна допуску

после школы

Нужен персональный proof по E01-E05

Каждый эксперт получает отдельный статус: слот, язык, анкета, пробный ответ, SLA, доступ, verdict.

↗качество

Пробный ответ обязателен

Без пробного ответа и scorecard эксперт не участвует ни в QA, ни в первом трафике.

↗
Школа v1 — это подготовка. Допуск — это отдельное PM-решение по конкретному человеку. Для QA нужен E01. Для первого трафика нужны E01-E05 или отдельный лимит capacity.

Решение PM

На июнь школа должна быть оформлена как простой рабочий контур: HTML/документы для обучения, тест, журнал допуска и ревизия Ксении. Красивую полноценную LMS-панель можно проектировать следующим слоем, после проверки первых 5 экспертов.

Что Ксения делает в этом контуре

роль

Ревизор понятности

Ксения проверяет, сможет ли реальный эксперт понять материал и выполнить задание без устного объяснения.

не роль

Не архитектор системы

Ксения не утверждает методологию, legal, архитектуру, приоритеты, оплату и финальный допуск. Она возвращает факты и замечания.

Допуск первых 5 экспертовGate перед контрольным заказом: обучение, пробный ответ, SLA, анкета, доступ и решение PM/QA.

Школа должна закончиться допуском

Лист приема E01-E05Обучение считается полезным только после proof-допуска конкретного эксперта.
