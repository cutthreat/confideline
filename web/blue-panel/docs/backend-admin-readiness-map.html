Что реально понятно по backend и админке Confideline

Confideline рассматриваем как реализованную платформенную базу. Но для Nebula запуск считается готовым только там, где доказана связка: клиентский экран → backend действие → админка → роль исполнителя → уведомления → поддержка → отчет.

Как это использовать

Для Игоря: брать не всю карту сразу, а красные блокеры по очереди: test order → рабочее место эксперта → поддержка → события/аналитика. Для Заказчика: эта карта объясняет, почему “бек есть” не равно “можно запускать рекламу”. Для PM: каждое желтое/красное место должно получить proof: скрин, отчет, CSV или публичную страницу результата.
