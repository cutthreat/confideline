Что отправить команде сейчас

Это актуальный рабочий пакет после сборки единого proof-светофора. Он превращает красные launch-gates в конкретные запросы: кому отправить, какие ссылки приложить, что вернуть и по каким правилам PM принимает результат.

Главный порядок

1. Игорь показывает safe control order и admin/no-send/support/analytics proof. 2. Ксения/PM закрывают минимум E01. 3. Только после READY запускается QA. 4. Антон параллельно ведет screen contracts. 5. Founder/legal/payment решения не закрываются PM.

Что не делаем

Не публикуем в Trello автоматически, не запускаем реальные платежи, письма, рекламу и production.

Правило приемки: результат без ID, скринов, ссылок и связки с capture sheet считается returned, а не accepted.

Короткий текст для отправки Игорю

Игорь, нужен один безопасный контрольный заказ Nebula/YouDate без реального списания и без реальной отправки писем. Нужно показать order_id, question_id, назначение исполнителя/анкеты, workspace исполнителя, ответ, no-send события, support/problem case, admin timeline и purchase analytics поля. Приемка идет по AOC01-AOC15, NSC01-NSC10, SPC01-SPC10, PAC01-PAC12. Если чего-то нет, верни как returned/blocker с причиной и где это должно быть реализовано.

Короткий текст для отправки Ксении

Ксения, нужен минимум один исполнитель E01, которого можно использовать в контрольном заказе. Нужно вернуть: кто это, язык/специализация, подтверждение обучения/регламента, пробный ответ, оценка по scorecard, SLA/окно доступности, назначенная анкета/profile, доступность к работе и verdict: accepted / accepted for QA only / returned / blocked. Общие слова “готов” не принимаются без фактов.
