Правила приемки

PASS

PAC01-PAC10 и PAC12 приняты на safe order. PAC11 может быть желтым до фактического повторного заказа, но должен иметь client_id/order history основу.

WARN

Основная цепочка source → session → order → value → service работает, но часть daily report, retention или error log пока ручная.

STOP

Нет source/session/order/value связки, нет currency, purchase event без order_id, не доказан safe payment mode или данные не попадают в report.
