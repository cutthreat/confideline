Что должно быть доказано, чтобы слой стал зеленым

Эта страница убирает спор “готово или не готово”. Для каждого слоя запуска указано: какой факт нужен, что уже есть, чего не хватает и где должен появиться proof.

Правило PM

Слой становится зеленым не по обещанию, не по ТЗ и не по скрину отдельной страницы. Нужен проверяемый факт: рабочий путь, отчет QA, ссылка на страницу Blue Panel, лог, скрин или утвержденный документ.

Главная проверка

Ключевой proof июня — контрольный заказ: входные данные → Игорь → QA → отчет → светофор.

Четыре главных proof-документа
