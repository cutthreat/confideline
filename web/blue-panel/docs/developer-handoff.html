Процесс работы

co2p-пакет для программиста

Что должно быть подготовлено перед передачей задачи в разработку.

Что строим

Результат, пользовательский сценарий, бизнес-смысл.

Макет

Интерактивная HTML-страница или набор экранов для согласования.

Связь с backend

Сущности, поля, статусы, роли, события, логи, ограничения.

Проверка

Критерии приемки и документ ожидаемого результата для тестировщика.

co2p-пакет нужен, чтобы программист внедрял осознанно, а не додумывал продукт сам.
