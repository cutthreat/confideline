Экспертский контур: что готово для запуска с первыми 5 экспертами

Эта карта объединяет школу, регламент, рабочее место, качество, начисления и поддержку. Для запуска недостаточно иметь 5 экспертов: нужно доказать, что каждый может пройти допуск, получить задачу, ответить в срок, быть проверенным и получить понятное начисление.

Как использовать

Для PM: сначала закрыть красные строки, связанные с работой первых 5 экспертов в реальной test consultation. Для Ксении: проверять подготовленные PM-материалы как ревизор, а не создавать архитектуру. Для Игоря: рабочее место эксперта, назначение, SLA, уведомления и начисления должны быть проверяемыми в админке.
