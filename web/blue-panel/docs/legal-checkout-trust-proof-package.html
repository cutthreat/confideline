PM-решение

Для первой версии держим one-time paid text consultation. Подписку не включаем, пока нет отдельного subscription/cancel gate. Документы должны описывать Nebula, а не legacy dating-сервис.

HTML-ready документы, карта мест показа, checkout microcopy, support/refund wording, связанные email/FAQ тексты и отдельный список founder/legal/payment решений.

Go / no-go

Можно передавать на согласование

Есть HTML-ready пакет с переменными, карта мест показа, checkout microcopy, support/refund варианты и список решений founder/legal/payment.

Нельзя публиковать checkout

Если тексты описывают legacy dating, не показывают disclaimer до оплаты, скрывают подписку, не объясняют support/refund path или не совпадают с фактическим checkout.
