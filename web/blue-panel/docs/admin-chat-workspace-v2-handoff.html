Admin chat workspace v2: контур для передачи в разработку

Этот контур относится к июньскому блоку admin chat / экспертский доступ. Его можно использовать как основу задачи Игорю после согласования с Заказчиком.

Что это

Веб-контур элементов и flow для рабочего пространства чата в админке.

Почему важно

Для Nebula/YouDate-N эксперт и агент должны закрывать платную консультацию внутри системы: видеть контекст, SLA, сообщения, статусы и действия.

Как использовать

Не как финальный backend, а как визуально-кликабельную основу co2p-пакета: постановка, связь с админкой, acceptance criteria и QA.

Доказательство

Открыть публичный web-контур admin chat workspace v2

PM-ограничение: локальный исходник этого web-контура в текущих проверенных путях не найден. Пока используем публичную ссылку как proof. При подготовке финальной карточки Игорю нужно связать публичный контур с конкретным локальным исходником/веткой, если он лежит в другом worktree.

Следующий шаг
