Ксения, ответ по R02 пока нельзя принять как E01 accepted for QA.

Не хватает:
- [указать недостающие данные по E01-E05: пробный ответ / язык / доступность / анкета / срок ответа / verdict]

Чтобы PM мог поставить accepted, нужно вернуть по каждому E01-E05:
1. имя или код эксперта;
2. язык;
3. доступность для тестового заказа;
4. анкета/профиль;
5. пробный ответ;
6. реальный срок ответа;
7. что осталось непонятным;
8. verdict READY / MINOR FIXES / BLOCKED;
9. кто является E01 для QA прямо сейчас.

До этого экспертный слой остается красным и QA не стартует.
