## PM-правило обработки

1. Сначала извлекать вложения из P0-карточек: email, чат, expert/admin roles, обучение, legal, QA, платежи, аналитика.
2. Для .docx, .pptx, .pdf, .md, .html делать текстовое извлечение и краткую PM-аннотацию.
3. Для .png/.jpg использовать визуальный просмотр только когда это макет, экран админки, схема или доказательство реализации.
4. Для .zip/.mhtml не тратить время без связи с P0: сначала определить карточку и цель.
5. Все извлеченные данные фиксировать не как “истина”, а как source extracted, затем делать PM-вывод.

## Что это значит для следующего прохода

Вложения не нужно распознавать все подряд. Нужно идти по P0-направлению и доставать только те материалы, которые влияют на решение, ТЗ или QA-документ.
