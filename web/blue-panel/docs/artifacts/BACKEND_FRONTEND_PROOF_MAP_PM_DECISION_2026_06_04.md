# Решение PM: карта связи фронта, backend и проверки

## Вывод
Проект нельзя оценивать одним статусом. Нужно проверять связки: экран → backend/admin → контент → состояния → proof. Дизайн и backend-база есть, но сквозная связка для Nebula пока не доказана.

## Что доказано как база
- Есть экранный контракт Nebula: 14 экранных групп и 89 блоков.
- Есть public Nebula pages и frontend/design слой.
- Confideline backend/admin является базой платформы.
- Описаны контуры покупки, админки, событий, поддержки, качества и начислений.

## Что не доказано
- Test order без реального платежа.
- Связь order → question → consultation → chat.
- Role-based expert/admin/support proof.
- No-send уведомления по сквозному маршруту.
- Support/refund ticket на test order.
- Отчет экономики по test order.

## PM-статус
Карта соответствия собрана. Следующий этап — превращать красные и желтые строки в co2p-пакеты для Игоря и проходить сквозной test/no-send сценарий.
