# Вывод PM по документам сайта и дисклеймерам

Текущие публичные документы Confideline подтверждают, что технически страницы документов на сайте есть, но они не готовы для Nebula.

Причина: содержание текущих Terms/Privacy/Cookie относится к dating/subscription-логике, профилям участников, подпискам, icebreaker-сообщениям и старой модели данных. Для Nebula нужна платная текстовая консультация, дисклеймер эзотерической услуги, прозрачная разовая покупка, support/refund процесс, privacy для чатов/экспертов/платежей и правила эксперта.

Статус: красный до рекламы.

Следующее действие: подготовить HTML-ready пакет с переменными и placeholders. Не публиковать финально до решения по юрлицу, платежному провайдеру, descriptor, refund window и географии запуска.
