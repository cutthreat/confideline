# Реестр доступов и заблокированных источников

Правило PM: не просить доступ “ко всему”. Просить только конкретную ссылку, источник карточки и причину, почему без нее нельзя принять решение.

Основные классы блокеров:

- Google Docs/Sheets/Drive: просить доступ, если документ влияет на P0, стратегию, обучение, legal или июньскую задачу.
- Figma: просить доступ, если без макета нельзя сверить frontend/личный кабинет/чат.
- Confideline 404: не просить доступ; сначала ремапить на текущие `/en/admin/...` маршруты или legal package.
- Timeout/ошибка: перепроверять точечно, только если ссылка нужна для текущего решения.

CSV-реестр: `ACCESS_REQUESTS_REGISTER_RU.csv`.
