# Пакет Игорю: рабочее место эксперта и агента

## Решение PM

Для запуска с первыми 5 экспертами не нужен отдельный красивый публичный кабинет эксперта. Достаточно рабочего места внутри админки Confideline по ролям, если исполнитель видит консультации, чат, срок ответа, контекст клиента, базу знаний, качество и начисления.

## Почему это важно

Без рабочего места экспертский контур неуправляем: после оплаты не ясно, кто отвечает, где видит задачу, когда истекает срок, как фиксируется жалоба, как создается начисление и кто контролирует качество.

## Граница пакета

- Работа через админку по ролям.
- Без реальных платежей и выплат.
- Без отдельного публичного кабинета эксперта.
- Без финального дизайна Nebula.
- Обязательно: роли, статусы, чат, события, качество, начисления и журнал действий.

## Статус

Пакет требований собран. Реализация и runtime-доказательство не выполнены, поэтому направление остается блокером запуска с экспертами.
