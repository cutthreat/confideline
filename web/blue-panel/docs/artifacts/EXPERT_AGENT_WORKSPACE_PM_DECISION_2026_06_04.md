# Вывод PM по рабочему месту эксперта и агента

На старте отдельный красивый личный кабинет эксперта не обязателен. Можно запускаться через админку с доступом по ролям, если для исполнителя это выглядит как цельное рабочее место.

Текущий статус: красный.

Что есть:
- публичный web-контур admin chat workspace v2;
- понимание, что роли могут работать через вкладки админки;
- июньская задача по рабочему месту эксперта/агента.

Что не доказано:
- список консультаций исполнителя;
- назначение и переназначение консультаций;
- срок ответа и просрочки;
- начисления;
- качество и замечания;
- уведомления исполнителю и администратору;
- ручная привязка анкет к экспертам/агентам;
- безопасное управление видимостью экспертов;
- сценарии проверки результата.

Решение PM: оформить это как отдельный пакет передачи Игорю: роли, вкладки, статусы консультации, чат, начисления, качество, уведомления, ограничения и тестовые сценарии.
