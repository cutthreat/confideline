# Решение PM: сквозная проверка запуска без реальных платежей

## Вывод
Готовность к запуску нельзя подтверждать отдельными страницами или макетами. Нужен один сквозной test/no-send маршрут: клиент → тестовая покупка → вопрос → назначение → ответ → уведомления → поддержка → качество → начисление → отчет.

## Запреты
- Не запускать реальные платежи.
- Не отправлять письма реальным клиентам.
- Не делать внешние публикации.
- Не считать рекламную готовность доказанной без test order ID, скриншотов, no-send логов и админских статусов.

## Минимум proof
- Скрин оффера.
- Test order ID.
- Карточка консультации в админке.
- Скрин рабочего места эксперта.
- No-send лог уведомлений.
- Support/refund ticket для проблемного сценария.
- Отчет экономики/событий.

## PM-статус
Сценарий проверки собран. Реальный проход еще не выполнен, поэтому этот слой остается обязательным следующим proof-этапом.
