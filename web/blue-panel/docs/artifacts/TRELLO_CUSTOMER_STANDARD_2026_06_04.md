# Регламент ведения Trello для Codex

## Главное
- Заголовок задачи описывает конечную цель, а не процесс.
- Цель не может быть «выполнить задачу».
- Постановка задачи остается в оригинале и не перетирается результатом.
- Результат выполнения добавляется отдельно.
- Комментарии используются только для важных апдейтов, остановок, недельных сводок и ссылок на результат.

## Обязательные разделы карточки
1. Цель.
2. Постановка задачи.
3. Конечный результат.
4. Временные затраты.
5. Ссылки.
6. Результат выполнения.

## Порядок ведения
- Выполнена: галочка слева.
- В работе: зеленая метка.
- Остановлена: красная метка и комментарий с причиной.
- Крупная задача: чек-лист на 3-6 этапов.
- По понедельникам: мини-сводка в комментарии.
- В конце месяца: отчет по задачам и процент выполнения плана.
