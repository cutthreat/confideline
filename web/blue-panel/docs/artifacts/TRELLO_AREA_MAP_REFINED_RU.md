# Уточненная карта областей Trello

Первичная карта была keyword-based. Этот проход уточняет ее с позиции PM: карточка относится не только по слову в названии, а по роли в запуске платформы.

| Область | Количество карточек |
|---|---:|
| общий-контекст/нужна-смысловая-сверка | 92 |
| чат-и-коммуникации | 53 |
| дизайн-и-фронт | 26 |
| qa-и-тестирование | 26 |
| nebula-вертикаль-и-эксперты | 25 |
| стратегия-и-маркетинг | 24 |
| админка-и-операционка | 17 |
| backend-и-разработка | 12 |
| email-и-уведомления | 8 |
| платежи-и-финансы | 4 |
| юридические-документы | 3 |
| другие-вертикали-платформы | 1 |

Ограничение: это все еще кабинетная классификация по выгрузке. Для карточек с пометкой “нужна ручная смысловая сверка” следующий проход должен читать тело карточки, комментарии справа, вложения и внешние ссылки.
