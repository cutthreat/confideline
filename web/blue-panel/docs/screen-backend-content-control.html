Карта экранов и функций перед запуском Nebula

Эта страница связывает Oracle/Nebula frontend, Confideline backend, контент, админку и проверку. Она нужна, чтобы не спорить “страница есть или нет”, а видеть, готов ли весь сценарий к запуску.

Главный вывод PM

Дизайн и backend-база есть, но ни один ключевой платный сценарий пока не доказан как полная связка: экран → действие → backend/admin → контент → QA.

Как использовать

Антону — недостающие состояния и экраны. Игорю — backend/admin связка. QA — сценарий проверки. Заказчику — почему нельзя запускать рекламу только потому, что есть макеты.
