Карта экранов, функций и текстов перед запуском Nebula

Здесь дизайн Oracle/Nebula проверяется как рабочий продуктовый слой, а не как набор картинок. Экран считается пригодным для запуска только если понятны действие клиента, backend/админка, контент, ошибки и QA-proof.

Главный вывод PM

У нас есть дизайн-источники и backend-база, но ни один ключевой платный сценарий пока не доказан как полная связка: экран → действие → backend/admin → контент → QA.

Что это меняет

Антону нельзя отдавать абстрактные правки “сделай красиво”, Игорю нельзя отдавать “сверстать экран”. Каждая задача должна идти как экранный контракт.
