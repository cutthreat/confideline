Операционный центр админки

Эта страница описывает, какой должна быть админка для запуска платной P2P-платформы: не набор разрозненных вкладок, а рабочий центр, где команда видит оплаченные консультации, назначение экспертов, просрочки, жалобы, возвраты, события, начисления и качество работы.

Решение PM

Админка должна быть центром управления сервисом. Для старта не обязательно делать отдельный красивый кабинет для всех ролей, но в админке должны быть понятные очереди, статусы, быстрые действия, права доступа и журнал событий. Сейчас этот слой описан, но его сквозная готовность не доказана экранами и тестовым сценарием.

концепция собрана готовность не доказана блокирует спокойный запуск рекламы

Что уже есть как основание

Есть backend Confideline, админка, web-контур admin chat workspace v2, карта событий, поддержка/возвраты и рабочее место эксперта.

Что не доказано

Не подтверждено, что админ видит полный путь: заказ → вопрос → назначение → ответ → проблема → возврат → начисление.

Что критично

Проблемы должны попадать в очереди автоматически: без вопроса, без назначения, скоро дедлайн, просрочено, жалоба, возврат.

Что нельзя

Нельзя запускать трафик, если админ узнает о проблемах только из ручного поиска, сообщений клиента или случайного просмотра чата.

Как админка должна вести команду

1. Утровидим новые заказы, просрочки, жалобы и задачи дня
2. Назначениеназначаем эксперта/агента и запускаем срок ответа
3. Контрольсмотрим кто отвечает, кто завис, где нужна помощь
4. Проблемажалоба, возврат или сбой попадают в отдельную очередь
5. Решениепереназначение, ответ, компенсация, ограничение, замечание
6. Отчеткачество, деньги, нагрузка и повтор видны в цифрах

Итог

Для запуска нам нужна админка-операторская, а не просто набор страниц. Главный критерий: утром PM/админ открывает один контур и видит, где деньги, где клиент ждет, где эксперт просрочил, где жалоба, где возврат, где сломалось уведомление и кто должен действовать. Пока это не доказано экранами и тестовым сценарием, слой остается красным для рекламы и желтым для подготовки разработки.
