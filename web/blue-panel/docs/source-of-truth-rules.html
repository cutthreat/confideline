Правила источников истины

Эта страница нужна не Заказчику первым экраном, а нам с тобой как PM-контур. Она фиксирует, где брать истину по каждому типу данных, чтобы Blue panel не подменяла Trello, старый CSV не подменял текущую карточку, а вывод PM не подменял доказательство.

Главное правило: Blue panel объясняет, связывает и показывает доказательства. Но она не является первичным источником для всего. Для каждого слоя есть свой источник истины.

Рабочая схема

Trello

Рабочая доска задач. Заголовки существующих карточек не трогаем. Изменения пользователя берем как актуальные.

Blue panel

Мастер-план, объяснение, доказательства, связи и результаты. Не подменяет первичные источники.

GitHub Pages

Публичная витрина результатов для Заказчика, Игоря, Ксении и тестировщика.

QA-отчеты

Доказательство работы или неготовности. Без проверки нельзя ставить зеленый статус.

Figma/верстка

Источник будущего фронта, но не доказательство работы backend.

Локальные отчеты

Архив фактов и промежуточных таблиц. Полезны, но уступают текущему Trello и runtime-проверке.
