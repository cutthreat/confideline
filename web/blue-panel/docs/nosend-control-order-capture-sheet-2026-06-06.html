Accepted proof

По каждому core event есть event_id, event_type, linked order/session object, recipient role, template, variables, preview screenshot/log, suppression marker и verdict.

STOP

Если ушло реальное сообщение или нет no-send/suppression marker, QA останавливается и блокер возвращается Игорю.

Правила приемки

PASS
  • NSC01, 02, 04, 05, 07, 08, 09 приняты.
  • external_send=false по каждому событию.
  • Есть preview или лог с переменными.
  • Все события связаны с test_run_id/order_id.
WARN
  • NSC03, 06, 10 работают частично или ручным fallback.
  • Core route доказан, но reminders/follow-up требуют ручного контроля.
  • QA может идти только с отмеченным риском.
STOP
  • Реальное письмо/SMS/push ушло наружу.
  • Нет no-send/suppression marker.
  • События не связаны с заказом.
  • Support/answer events отсутствуют.
