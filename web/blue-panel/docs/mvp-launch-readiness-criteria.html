MVP readiness criteria · 05.06.2026

Что должно быть доказано для тестового запуска MVP

Это критерии “можно идти к первым клиентам”. Они отделяют подготовленный PM-пакет от реальной готовности сайта, экспертов, админки, поддержки, уведомлений и QA.

1 зеленый5 желтых8 красныхMVP еще нельзя запускать
PM-решение

MVP нельзя считать готовым, пока красные критерии не закрыты runtime proof. Основной путь: safe test order, question binding, workspace, admin visibility, no-send, support, first 5 experts и QA verdict.

Как менять статус

Статус меняется только по ссылке на proof: скрин, лог, QA-отчет, CSV или опубликованная страница. Не по ощущению готовности.

0QA PASS по контрольному заказу
Go/no-go правило: первый тестовый трафик возможен только после контрольного заказа и QA verdict. До этого можно готовить материалы, но нельзя считать MVP готовым.
