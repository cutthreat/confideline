Как использовать карту

Для Антона: правки должны идти не просто по красоте, а по клиентскому пути: понять оффер, довериться, выбрать услугу, зарегистрироваться, купить, задать вопрос, получить ответ. Для Игоря: каждый экран получает backend/admin связь и состояния ошибок. Для Заказчика: эта карта показывает, что дизайн есть, но его еще нужно связать с сервисом, а не просто сверстать.
