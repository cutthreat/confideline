Что делать дальше без распыления

Это короткая операционная доска текущего шага. Она не заменяет мастер-план, а показывает ближайшие действия, которые двигают нас к первому доказанному контрольному заказу.

runtime QA пока STOPPM/QA готовят фикстурыhandoff Игорю готов
Главное решение

Не добавлять новые функции и не обсуждать рекламу до закрытия AC01-AC09 и QA-отчета по одному test order.

Что сейчас можно делать автономно

Заполнить желтые фикстуры, держать пакет Игорю, подготовить QA before-state и после каждого факта обновлять readiness.
