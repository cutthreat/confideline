Карта “источник → PM-вывод → действие”

Эта страница показывает, откуда взяты ключевые решения проекта: Trello, Google-исследования, AskNebula/PbExpert, backend Confideline, дизайн Oracle/Nebula, QA-контур, legal/checkout и runtime proof. Цель — чтобы каждое решение было проверяемым, а не выглядело как мнение PM.

Главное правило

Источник может поддерживать решение, но не всегда доказывает готовность. Trello, Google и дизайн дают контекст. Runtime test order, допуск исполнителя и QA дают запусковый proof.

Как использовать

Если возникает вопрос “почему мы это делаем”, открываем строку источника: какой вывод сделан, где он отражен и какое действие из него следует.

2источника являются рабочим PM-стандартом
11источников дают решения, но требуют проверки/фактов
1критичный источник пока отсутствует: runtime facts
14цепочек источник → решение → действие
Ограничение: эта карта не закрывает запуск. Она закрывает прослеживаемость решений. Запуск закрывает только контрольный заказ, QA, допуск экспертов, support/no-send и founder/legal/payment gates.
PM-вывод: контекст по проекту теперь достаточно систематизирован. Следующий прирост качества должен идти не от новых исследований, а от фактов на рабочем пути услуги.
