План собран из реального списка Trello “План на Июнь” и P0-задач мастер-плана. Trello пока не менялся: эта страница является основой для согласования и следующего переноса/обновления карточек.

Главное действие на этой странице
Согласовать набор задач июня на 160 часов, затем переносить/обновлять карточки Trello по стандарту результата.
PM-цель старта
