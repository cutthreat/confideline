Решение PM

Checklist-пункт “Добавить нужный контент для каждого экрана” можно закрывать как PM-результат. Для каждого ключевого экрана задан content layer: публичный текст, UI-тексты, назначение, ограничения и gate. Это не означает, что тексты уже опубликованы на production или юридически утверждены.

Граница закрытия

Закрыто: PM сформировал нужный content layer для всех 16 областей запуска: оффер, регистрация, услуги, карточки экспертов, покупка, вопрос, чат, кабинет, экспертская админка, школа, support, email, юридика, блог/прогрев, модерация, QA.

Не закрыто этим пакетом: публикация на production, переводческая редактура носителем, юридическое утверждение, платежный descriptor/provider, runtime-проверка оплаты и отправки писем. Это отдельные gates, а не причина держать контентный PM-пункт открытым.
