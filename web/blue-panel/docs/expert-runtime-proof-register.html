PF05-PF07 · expert runtime proof · 05.06.2026

Исполнитель должен реально увидеть задачу, ответить и закрыть статус

Этот реестр доказывает, что первые 5 экспертов — не просто люди в списке, а рабочий ресурс платформы. Контрольный заказ должен показать назначение, доступы, контекст, ответ, срок, качество и тестовое начисление.

Решение PM

Для MVP не нужен отдельный красивый кабинет эксперта. Достаточно админки по ролям, если QA докажет: исполнитель видит только свою задачу, понимает срок и вопрос, отвечает в связанном чате, а система фиксирует статус, события и последствия.

Связь с 5 экспертами

PF05-PF07 можно закрывать только на исполнителе, который прошел EP01-EP09 или явно помечен как условно допущенный только для теста.
