Откуда берется PM-понимание проекта

Эта карта показывает, какие источники уже используются как доказательная база, где источник надежен, где он частичный, а где без нового доступа или runtime-проверки нельзя делать сильный вывод.

1 зеленый источник12 частичных источников1 критичный пробел
Зачем эта страница

Чтобы PM-решения не выглядели как мнение. Каждый вывод должен опираться на источник: страница, карта, CSV, Trello, runtime proof, QA-отчет или явно отмеченный пробел доступа.

Правило доверия

Trello и документы дают контекст. Runtime сайт, допущенный исполнитель, скрины, логи и QA дают доказательство работы. Если runtime proof отсутствует, статус остается желтым или красным.

1источник можно считать опорным
12источников частично покрывают проект
1источник требует runtime proof
14источников и контуров учтено
PM-решение: использовать Blue Panel как слой выводов, но не смешивать выводы с фактами. Для каждого спорного слоя нужен либо source extraction, либо runtime proof.
