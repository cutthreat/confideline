Это контрольная страница для решения “можно ли запускать рекламу”. Она собирает в одном месте клиентский путь, backend, админку, экспертов, уведомления, поддержку, QA и маркетинг.

Решение PM

Первый запуск нельзя оценивать по наличию лендинга или чата отдельно. Готовность появляется только когда один тестовый заказ проходит весь маршрут от оффера до ответа и support без реальных списаний и реальных писем.

Практический маршрут закрытия

СначалаПодтвердить test order без списания: заказ, вопрос, клиент, админка.
ПотомСвязать исполнителя, SLA, чат и ответ с конкретной консультацией.
ЗатемДобавить no-send уведомления, support case и problem states.
После этогоЗапустить QA-проход и только по PASS/WARN/STOP решать про малый трафик.
