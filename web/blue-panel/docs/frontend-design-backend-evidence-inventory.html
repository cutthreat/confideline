Реестр экранов и доказательств по Nebula

Это не список красивых макетов. Это PM-реестр, где каждый экран оценивается по четырем слоям: визуальный источник, backend/админка, контент и QA-proof. Зеленый статус не ставится, пока экран не доказан в рабочем сценарии.

5 желтых зон10 красных зон0 зеленых экранов MVPреестр создан
PM-вывод

У нас есть дизайн-источники и часть публичных/локальных доказательств, но платный путь Nebula пока не доказан как продукт: checkout, вопрос, ответ, support, no-send и админка остаются красными.

Как использовать

Для Антона это карта недостающих экранных состояний. Для Игоря — список backend-связей. Для QA — перечень того, что нужно снять скринами по test order.

5есть визуальная/документальная база

0зеленых зон для MVP
Правило: Figma/PNG/HTML сам по себе дает только желтый статус. Зеленый появляется только при связке “экран → действие → backend/admin → контент → error state → QA evidence”.
