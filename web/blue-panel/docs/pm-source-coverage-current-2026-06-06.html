Классы надежности источников

A · Runtime proof

ID заказа, admin timeline, no-send log, support case, QA report. Только это двигает запуск к зеленому.

B · Текущие рабочие источники

Trello, Blue Panel, принятые задачи, result links. Это управляет работой, но не заменяет runtime.

C · Исторические исследования

Google Docs/Sheets, старые исследования, материалы конкурентов. Это база решений, но ее надо сверять с текущим состоянием.

D · Контекст/benchmark

AskNebula, PbExpert, рекламные политики, конкуренты. Полезно для стандартов, но не является доказательством нашей готовности.
