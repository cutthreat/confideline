PM-решение

Эту страницу использовать как приемку ежедневной операционной панели. Если пункт нельзя увидеть без ручного поиска по разным разделам, он считается неготовым для запуска трафика.

Граница MVP

Отдельный красивый личный кабинет эксперта не обязателен на первый тест, если админка по ролям закрывает маршрут: заказ → назначение → ответ → support → начисление → отчет.

Что админ должен видеть каждый день

УтромНовые заказы, без вопроса, без исполнителя, просрочки, жалобы, недоставленные события.
В течение дняНазначения, ответы, SLA, support, качество, нагрузка экспертов, риск refund.
ВечеромЗакрытые заказы, незакрытые проблемы, начисления, нарушения, список действий на завтра.
Для PMНе общий шум, а светофор: что можно считать готовым, что мешает трафику, кто следующий владелец.

Go / no-go

Нельзя включать трафик: если админ не видит новые заказы, назначение исполнителя, SLA, support-кейс, no-send события и аналитику покупки.
Минимальный WARN для первого QA: AV01, AV03, AV04, AV05, AV06, AV07 должны иметь runtime proof. AV08-AV12 могут быть желтыми, если есть ручной регистр и понятный владелец.
