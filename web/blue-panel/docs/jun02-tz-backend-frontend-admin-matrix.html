Связь старых ТЗ с сайтом, админкой и фронтом

Это не новая постановка задач. Это PM-сопоставление уже найденных Trello-карточек с тем, как они влияют на запуск Nebula: backend Confideline, будущий frontend Oracle/Nebula, админка, proof и следующий шаг.

Главный вывод

Из 10 старых карточек 7 полезны для ядра или ближайшего запуска Nebula, 2 уже частично покрыты email-пакетом, 1 GEO-блок нужно держать отдельно.

Что это закрывает

Закрывается checklist-пункт “Определить связь с сайтом, админкой и будущим фронтом Oracle/Nebula” в карточке “Прогнать все макеты готовых ТЗ через Codex”.
