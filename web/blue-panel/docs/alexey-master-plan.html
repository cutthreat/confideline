Что блокирует запуск

Нет runtime proof платной консультации.
Нужен один тестовый путь: оффер → заказ → вопрос → назначение → ответ → уведомления → поддержка → закрытие.
Не доказана операционная видимость в админке.
Админ должен видеть статус заказа, эксперта, клиента, события, проблемы и финансовый след без ручного поиска.
Не подтвержден допуск 5 экспертов.
Нужны обучение, тест, пробные ответы, SLA и ручное подтверждение допуска.
Юридика и платежи остаются gate.
Это не мешает готовить пакет, но без legal/payment approval нельзя боевой checkout.
