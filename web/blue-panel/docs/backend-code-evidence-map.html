Что реально найдено в backend-коде

Эта страница отделяет факты от предположений: какие кирпичи уже есть в кодовой базе Confideline, какие лежат как макеты/пакеты, а где нет доказанной связки для запуска Nebula.

Главный вывод PM

В backend есть серьезная универсальная база: пользователи, профили, чат, сообщения, переводы, уведомления, баланс, платежные формы, заказы, заявки экспертов, жалобы и блокировки. Но доменный слой платной консультации Nebula пока не доказан как единый рабочий маршрут.

Что это значит для июня

Сначала не расширяем список функций, а просим Игоря подтвердить или связать test order: заказ → вопрос → назначение → чат → ответ → события → support → QA.

6слоев имеют кодовую базу
5слоев требуют связки или настройки
3слоя блокируют запуск без runtime proof
1первый шаг: test order
Источник прохода: выбран base Yii2 пакет Confideline/Chat/youdate-2.0.2-yii2/Source/youdate_extracted/application. Отдельно учтен handoff-макет чата Confideline/Chat/admin-chat-workspace-v2 и preview-пак уведомлений Confideline/notification-preview-pack. Архивы не использовались как source of truth.

Решение PM

Не переписывать backend с нуля. Использовать существующие кирпичи Confideline: user/profile/message/order/payment/notification/report/block. Отдельно довести недостающий слой платной консультации и доказать его одним сквозным тестом. Это самый короткий путь к MVP с 5 экспертами.
