Пакет сбора runtime-доказательств

Это рабочая приемка для красных блокеров. Она отвечает не “что еще написать”, а какие конкретные ID, скрины, логи и публичные ссылки нужны, чтобы пересчитать готовность запуска по фактам.

9 красных доказательств3 желтых правила0 фактов снято сейчасформат приемки готов
PM-решение

До появления этих доказательств нельзя честно ставить зеленый статус клиентскому пути, админке, рабочему месту эксперта, support, уведомлениям и первому трафику.

Практическое правило

Каждый факт должен иметь ID заказа/сессии или другой общий marker. Разрозненные скрины без связи с контрольным заказом не принимаются.

12групп evidence для приемки
0runtime-фактов снято сейчас
4владельца: Игорь, QA, PM, Ксения
1итог: пересчет светофора запуска
Что не является доказательством: устное “работает”, отдельный скрин без ID, чек-лист без runtime, реальный платеж, реальная отправка писем, файл без понятного имени и владельца.
