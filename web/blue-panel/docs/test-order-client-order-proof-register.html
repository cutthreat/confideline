PF00-PF04 · client/order runtime proof · 05.06.2026

Клиентский оффер должен превратиться в управляемую консультацию

Этот реестр доказывает начало платной услуги: клиент понимает оффер, создается безопасный тестовый заказ, админ видит order, вопрос связан с заказом, а поверх этого появляется карточка консультации.

Решение PM

До PF05-PF09 нет смысла проверять эксперта, уведомления и support, если не доказаны первые четыре факта: заказ безопасен, виден в админке, вопрос не потерян, консультация стала рабочей сущностью.

Граница безопасности

Только test/sandbox/mock. Никаких реальных списаний, писем, выплат и внешних клиентов.
