Как показывать

Panel HTML-ТЗ Admin GitHub

Прямые адреса

Короткие ссылки и пути для вставки в задачу, чат или handoff.

web/panel-name.html
web/panel-name-spec.html
application/modules/.../view.php

Checklist

  • Есть одна dedicated panel page.
  • Есть отдельная HTML-spec page.
  • Есть прямой admin URL или честно указано, что нужен локальный runtime.
  • Есть source of truth и реальные файловые пути.
  • Если есть итерации дизайна, версии `v1 / v2 / v3` вынесены явно.
