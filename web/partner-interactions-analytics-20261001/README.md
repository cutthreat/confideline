# Панель взаимодействий №59 — макеты и ТЗ для Игоря

Открыть [админский макет](admin.html), [агентский](partner.html) или [экспертный](expert.html). [ТЗ](TZ.md) описывает требуемый результат, поведение и учитываемые данные; визуальный состав — по HTML. Вкладка графиков открывается из отчёта.

Управление отчётом работает с примером данных. Боковое меню сохраняет исходный визуальный каркас кабинета; переходы в другие разделы отключены до внедрения. Тестовых переключателей, скрытого режима проверки и симуляторов нет. Числа и участники в HTML — статический пример наполнения, не данные сайта; их не переносить как фактическую статистику. Фильтры, столбцы, сортировка, страницы и графики работают с этим примером. Генераторы и расчётные проверки находятся вне пакета для вёрстки.

Макеты открываются локально без установки библиотек и сетевых запросов. Результат не является внедрением на сайт. После реализации сверить поведение и права по разделу «Как принять» ТЗ. Актуальная редакция: 08.10.2026, r14. Проверены расчёты, фильтры, таблицы, графики и управление клавиатурой для трёх ролей; просмотрены широкая и мобильная версии. Серверная реализация, доступы API и реальные источники требуют отдельной приёмки.

Порядок работы: полная сводка → открытые «Фильтры отчёта» → вкладки «Таблица / Графики» → содержимое отчёта. В блоке «Показатели таблицы», над ручным выбором столбцов, находятся «Готовые наборы»: Обзор, Нагрузка, Обращения, Результат, Качество. Они меняют только столбцы таблицы, сохраняя полную сводку, текущую выборку, неприменённый ввод и настройки/участников/график. «Обзор» возвращает шесть основных столбцов; ручная правка отмечается как «Свой набор». Можно добавить или убрать любой столбец. Графики настраиваются самостоятельно в своей вкладке. Кнопка «Основные» убрана как дубль набора «Обзор».

Выбор показателей и сортировка постоянно открыты перед таблицей; параметры графика видны сразу. Исходная компоновка и визуальный каркас бокового меню сохранены.

Граница примера: счётчик «Новые диалоги» ещё основан на первом сообщении клиента в паре; отдельного счётчика Pings здесь нет. Сводка по выбранным профилям и агентские агрегаты реализованы в макете; реальные назначения, источники и серверные права не подтверждены. Уточнённая целевая модель Chat/Ping и передачи анкет описана в ТЗ; её реализацию проверять отдельно.

В r13 убраны служебные объяснения механики интерфейса: наведение/фокус, мобильные подписи, инструкции по кликам и применению, повторяющиеся пояснения выборки. Статусы сокращены. Сохранены рабочие подписи, ошибки, подсказки о смысле показателей, единицы/даты LTV и обозначения сравнения периодов.


В r14 в «Фильтрах отчёта» доступен множественный выбор профилей, сгруппированных по текущим агентам. У агента доступны только его профили, у эксперта — фиксированный собственный профиль. Выбор группы отмечает все её профили; частичный выбор имеет промежуточное состояние. Поиск не меняет выбор. «Применить фильтры» обновляет сводку, таблицу и графики; пустой выбор показывает ошибку и сохраняет предыдущий отчёт. «Отменить изменения» возвращает применённый набор.

Администратор сравнивает «Профили экспертов» либо «Агентов» в графиках. Агентский агрегат включает только отмеченные у этого агента профили; рядом показано их количество, в подсказке — состав. Checkbox участников графика меняют видимость рядов и не подменяют общую выборку. Выбранные профили без событий остаются нулевыми рядами; неизвестные данные не становятся нулями. Порядок агентов сохраняется при изменении состава.

Внутренние partner/partnerId и имя partner.html сохранены для совместимости примера; пользовательские названия — «Агент». Это не доказательство соответствия конкретной роли/таблице на сайте.
