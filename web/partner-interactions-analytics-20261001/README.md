# Панель взаимодействий №59 — пакет для Игоря

Редакция **r17 · 09.10.2026**. Открыть [вход](index.html), [администратор](admin.html), [агент](partner.html), [эксперт](expert.html). [Единое ТЗ с картой приёмки](TZ.md).

Распаковать архив и открыть index.html. Установка библиотек и доступ к сети не нужны; Inter и его лицензия включены. Числа и участники — демонстрационный пример, не статистика сайта.

Порядок: полная сводка → открытые фильтры → вкладки «Таблица / Графики». Общий выбор одного/нескольких/всех профилей сгруппирован по текущим агентам. Можно задать отдельное подмножество у каждого агента; оно определяет сводку, таблицу и агентские агрегаты. Поиск не меняет выбор. Применение обновляет отчёт, отмена возвращает применённые значения. Пустой выбор и ошибочный ввод сохраняют прежний отчёт и показывают ошибку.

Готовые наборы меняют только столбцы таблицы. «Обзор» содержит шесть показателей; ручной выбор свободный. Настройки графиков независимы, галочки участников управляют видимостью рядов. Выбранные профили без событий остаются нулевыми рядами; неизвестный источник даёт «Нет данных» с причиной. Цвет закреплён за типом и ID участника.

Новые Chats/Pings считаются по отдельным датированным фактам, не выводятся из сообщений/просмотров. LTV агента — сумма LTV пар по выбранным профилям. Платформенный LTV относится к клиенту и учитывается один раз. Передача профиля меняет текущий доступ к его истории, сохраняя сами факты; серверный контракт и приёмка описаны в ТЗ.

В r17 применены типографика, плотность таблиц, линии и поля из переданных admin/contact-filter образцов. На телефоне сохранены удобные области касания и локальная прокрутка таблиц. Компоновка и расчёты r16 сохранены. Макет русскоязычный; проверка английских длинных подписей является проверкой геометрии, не готовым переводом.

Проверены 89 расчётных сценариев и 96 браузерных проверок: три роли, 1440/1024/768/390/360px, клавиатура, выбор профилей, агрегаты, ошибки, таблицы и графики. Внутренние проверки и происхождение ресурсов хранятся отдельно от пакета.

Это интерактивная вёрстка и ТЗ на демонстрационных данных. Backend, реальные источники, API/RBAC и передача профилей требуют приёмки на именованном стенде по карте в ТЗ. Боковое меню сохраняет исходный каркас; переходы в другие разделы отключены до интеграции. Внутренние partner/partnerId и partner.html оставлены для совместимости примера; пользовательское название — «Агент».
