# Взаимодействия №59 — вёрстка и ТЗ

**r18 · 11.10.2026.** Открыть [вход](index.html), [макет администратора](admin.html), [макет агента](partner.html), [макет эксперта](expert.html). [ТЗ и карта приёмки](TZ.md).

Распаковать ZIP и открыть index.html. Установка и сеть не нужны: стили, скрипты, Inter и лицензии включены.

Сводка, таблица и графики используют один применённый набор профилей. У администратора выбор сгруппирован по агентам; можно задать свой состав у каждого агента. Наборы столбцов и видимость рядов графика управляются независимо. Правила расчётов, права, состояния и критерии внедрения описаны в едином ТЗ.

Данные демонстрационные. Backend, реальные источники и серверные права принимаются на именованном стенде по карте в ТЗ. Боковое меню сохраняет каркас кабинета; переходы вне отчёта подключаются при интеграции. Статический макет русскоязычный; продуктовые переводы подключаются через существующие словари.
