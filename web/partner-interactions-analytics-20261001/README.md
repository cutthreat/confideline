# Панель взаимодействий №59 — макеты и ТЗ для Игоря

Открыть [админский макет](admin.html), [партнёрский](partner.html) или [экспертный](expert.html). [ТЗ](TZ.md) описывает требуемый результат, поведение и учитываемые данные; визуальный состав — по HTML. Вкладка графиков открывается из отчёта.

В интерфейсе только рабочие элементы. Тестовых переключателей, скрытого режима проверки, симуляторов, служебных ссылок и отметок прототипа нет. Числа и участники в HTML — статический пример наполнения, не данные сайта; их не переносить как фактическую статистику. Фильтры, столбцы, сортировка, страницы и графики работают с этим примером. Генераторы и расчётные проверки находятся вне пакета для вёрстки.

Макеты открываются локально без установки библиотек и сетевых запросов. Результат не является внедрением на сайт. После реализации сверить поведение и права по разделу «Как принять» ТЗ. Актуальная редакция: 01.10.2026, r6. Новая визуальная/клавиатурная приёмка этой редакции ещё не выполнена.
