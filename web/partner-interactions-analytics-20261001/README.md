# Панель взаимодействий №59 — макеты и ТЗ для Игоря

Открыть [админский макет](admin.html), [партнёрский](partner.html) или [экспертный](expert.html). [ТЗ](TZ.md) описывает требуемый результат, поведение и учитываемые данные; визуальный состав — по HTML. Вкладка графиков открывается из отчёта.

В интерфейсе только рабочие элементы. Тестовых переключателей, скрытого режима проверки, симуляторов, служебных ссылок и отметок прототипа нет. Числа и участники в HTML — статический пример наполнения, не данные сайта; их не переносить как фактическую статистику. Фильтры, столбцы, сортировка, страницы и графики работают с этим примером. Генераторы и расчётные проверки находятся вне пакета для вёрстки.

Макеты открываются локально без установки библиотек и сетевых запросов. Результат не является внедрением на сайт. После реализации сверить поведение и права по разделу «Как принять» ТЗ. Актуальная редакция: 08.10.2026, r10. Проверены расчёты, фильтры, таблицы, графики и управление клавиатурой для трёх ролей; просмотрены широкая и мобильная версии. Серверная реализация, доступы API и реальные источники требуют отдельной приёмки.

Порядок работы: сводка → открытые «Фильтры отчёта» → вкладки «Таблица / Графики» → содержимое отчёта. Четыре готовых набора и «Обзор» находятся внутри фильтров; поля свободной настройки всегда видны и доступны. Наборы сохраняют текущую выборку и неприменённые значения полей. «Обзор» возвращает полную сводку. Столбцы можно дополнительно настроить вручную.

Граница примера: счётчик «Новые диалоги» ещё основан на первом сообщении клиента в паре; отдельного счётчика Pings и сводки по агенту здесь нет. Уточнённая целевая модель Chat/Ping и передачи анкет описана в ТЗ; её реализацию проверять отдельно.
