Что нужно получить на боевом сайте

В текущих страницах управления страной и городом появляются вкладки: Информация, Описание, Изображения, FAQ, SEO, Переменные. Управление городами/регионами и экспертами не входит в карточку страны или города.

  • Системные поля остаются в текущем виде: ID, slug, geoname id, ссылка, active, show on main, language.
  • Контент и SEO редактируются для выбранного языка через существующий select Language.
  • Основной HTML-текст остается в TinyMCE.
  • Фото остаются в текущем uploader-контуре, но получают alt/title/description.
  • Перед сохранением показывается понятная проверка ошибок.

Стандарт на будущее

Для всех похожих страниц Confideline page-specific код выносится в отдельные файлы custom.css и custom.js, подключенные через отдельный AssetBundle. Глобальные стили админки не меняются ради одной страницы.

web/static/admin/geo-page/custom.css
web/static/admin/geo-page/custom.js

AssetBundle

namespace app\modules\admin\assets;

use yii\web\AssetBundle;

class GeoAdminPageAsset extends AssetBundle
{
    public $basePath = '@webroot/static/admin/geo-page';
    public $baseUrl = '@web/static/admin/geo-page';
    public $css = ['custom.css'];
    public $js = ['custom.js'];
    public $depends = [
        'yii\web\YiiAsset',
        'yii\bootstrap\BootstrapAsset',
    ];
}

Подключение во view

use app\modules\admin\assets\GeoAdminPageAsset;

GeoAdminPageAsset::register($this);

Форма

Оставить текущий ActiveForm. Вкладки и partials вставляются внутрь существующей формы, чтобы кнопка Обновить работала как сейчас.

Submit

Главное сохранение остается обычным submit формы. Это базовая надежность: даже если JavaScript или AJAX временно сломались, админ может сохранить страницу штатным способом.

AJAX

  • POST /admin/geo/preview — вернуть HTML-предпросмотр текущей языковой версии.
  • POST /admin/geo/validate — вернуть список предупреждений перед сохранением.
  • POST /admin/geo/variables — опционально вернуть актуальную карту переменных, если она будет храниться на сервере.

Чек-лист приемки

  • Страница страны и страница города используют одну структуру вкладок.
  • Языки работают через существующий select Language.
  • Системные поля не потеряны и read-only остаются read-only.
  • Meta Title показывает счетчик и предупреждение после 70 символов.
  • Meta Description показывает счетчик и предупреждение после 160 символов.
  • Переменные имеют hint при наведении и копируются кликом.
  • Верхние индикаторы готовности ловят отсутствие Cover Photo, FAQ меньше 4, пустой HTML, ошибки SEO и слово Neiro вместо {{siteName}}.
  • Submit работает без AJAX.
  • AJAX preview не ломает форму, если endpoint недоступен.
  • Нельзя переносить в карточку страны/города вкладки “Города и регионы” и “Эксперты”.
