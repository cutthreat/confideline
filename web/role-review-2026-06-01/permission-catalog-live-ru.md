# Live-справочник прав админ-панели Confideline

Источник: `https://confideline.com/ru/admin/role/update?id=2`

Всего найдено прав: 72. CSRF/cookie/token значения не сохранялись и не выводились.

## Как читать ключи

| Часть ключа | Смысл |
|---|---|
| `-all` | Полный доступ к модулю: смотреть, менять, удалять и выполнять специальные действия, если они есть в controller. |
| `-view` | Просмотр/чтение. Для чужих/своих объектов все равно нужен row-level scope. |
| `-update` | Создание/изменение/status/toggle/approve. Требует audit log. |
| `-delete` | Удаление. Высокий риск. |
| `-balance` | Балансовые/финансовые данные. |
| `users-agent` | Специальный агентский users-key, не заменяет assigned expert scope. |
