Content variables: implementation notes

Эта страница не является частью боевого UI. Здесь собраны пояснения для программиста по мультиязычности, сценариям проверки и backend-контракту.

Что взято из текущей админки

Layout

main.php: hold-transition skin-youdate fixed sidebar-mini, main-header, main-sidebar, content-wrapper, content-header, content.

UI pattern

box, box-primary, box-solid box-nav, table table-vcenter, form-control, btn btn-primary, label, small-box.

Current language model

LanguageController uses list, translate, save. Data model: language, language_source, language_translate.

Translator settings

System -> Translator remains provider configuration. Content variable values must live in a separate registry, not in provider settings.

Implementation rule

Не переносить подсказки из этой страницы в боевой UI. Боевой экран должен остаться чистым: таблица, фильтры, модальное редактирование, переводы, usage и audit. Все пояснения для Codex/Игоря остаются здесь.
