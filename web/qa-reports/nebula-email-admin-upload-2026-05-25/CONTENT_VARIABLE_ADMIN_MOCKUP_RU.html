What to connect

  1. Запустить локального fake-provider: cd H:\GPT-Codex\Confideline\payment_sandbox\confideline-stripe-sandbox php -S 127.0.0.1:8787 server.php
  2. В локальных настройках сайта направить Stripe API на sandbox: CONFIDELINE_STRIPE_API_BASE=http://127.0.0.1:8787 paymentStripeSecretKey=sk_test_confideline_sandbox paymentStripeWebhookSecret=whsec_confideline_sandbox_local_only
  3. В адаптере Yii2 выставить Stripe API base и возвращать checkoutUrl из create-session, чтобы фронт мог перейти на локальный checkout.
  4. Прогнать сценарии: php run-sandbox-scenarios.php --base-url http://127.0.0.1:8787 --site-url http://127.0.0.1:8092
