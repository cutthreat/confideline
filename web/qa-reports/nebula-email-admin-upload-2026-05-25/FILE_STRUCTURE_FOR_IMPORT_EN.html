Email template file structure

This page documents the agreed file structure. File names are identical across all templates. English is the primary implementation language. Russian is the second localization.

Decision: one email scenario equals one folder templates/NN_template_code/. Inside it, use only en/ and ru/. There are no root-level duplicate template files inside scenario folders.

Do not confuse file names and events

template_code is the package folder/scenario name. event_name is the backend/admin trigger key. Existing system events such as user.register, user.email_confirmation, and payment.success stay in settings because the current backend depends on them. They are not file names.
