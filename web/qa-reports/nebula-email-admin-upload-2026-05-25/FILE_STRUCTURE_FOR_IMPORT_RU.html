Единый стандарт файлов для внедрения

Эта страница закрывает вопрос по структуре: названия файлов внутри каждого шаблона должны быть одинаковыми, а старые системные события не должны путаться с именами файлов.

Принятое решение: один сценарий письма = одна папка templates/NN_template_code/, внутри только две языковые папки en/ и ru/. Корневые дубли файлов удалены из пакета.
19сценариев письма
38языковых комплектов: 19 EN + 19 RU
6одинаковых файлов в каждой языковой папке

Структура одного шаблона

templates/NN_template_code/
  en/
    subject_email.txt
    preheader_note.txt
    body_email_html.html
    body_email_txt.txt
    comment_about.txt
    admin-meta.json
  ru/
    subject_email.txt
    preheader_note.txt
    body_email_html.html
    body_email_txt.txt
    comment_about.txt
    admin-meta.json

Важно про старые события

template_code - это наше понятное имя папки и сценария. event_name - технический ключ backend/админки. События вроде user.register, user.email_confirmation, payment.success остаются в настройках, потому что они уже есть в системе или должны быть добавлены в backend. Это не названия файлов.
