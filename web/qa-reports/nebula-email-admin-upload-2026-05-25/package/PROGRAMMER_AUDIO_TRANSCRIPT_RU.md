## Рабочий вывод для пакета email-шаблонов

1. Шаблоны нужно готовить как значения для текущей админки, а не как отдельную новую систему верстки.
2. Базовый процесс импорта: сначала английский текст, затем переводы. Русский пакет нужно внедрять как RU-локализацию или после EN-base.
3. Нельзя добавлять произвольные новые переменные в шаблон. Использовать только переменные, доступные конкретному template/event.
4. Если нужна новая переменная, это отдельное изменение backend-кода и renderer-контракта.
5. Queue/очередь отправки является отдельной зоной проверки: часть template events уже обрабатывается, часть еще не подключена к очередям.
6. Для каждого шаблона перед активацией нужно подтвердить не только `event_name`, но и queue-binding: когда событие попадает в очередь, какие данные передаются и не будет ли дублей.
