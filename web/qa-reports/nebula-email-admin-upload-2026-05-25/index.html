Готово для загрузки

  • Сценарии ограничены текущим этапом: только онлайн-консультация через чат.
  • Название продукта вынесено в переменную {{siteName}}, без жесткой привязки к рабочему названию проекта.
  • HTML подготовлен как фрагмент для поля body_email_html, без doctype/html/head/body.
  • Для каждого сценария есть отдельные папки en/ и ru/ с одинаковыми trigger-настройками.
  • Добавлена страница двуязычного просмотра: TEMPLATES_PREVIEW_RU_EN.html.
  • Добавлена страница визуального просмотра всех писем: TEMPLATES_PREVIEW_RU.html.
  • Добавлена матрица сценариев и настроек: TEMPLATE_SETTINGS_SCENARIOS_RU.html.
  • Новые и неподтвержденные переменные вынесены отдельно: VARIABLES_CONTRACT_RU.html.
  • Публичный пакет не содержит CSRF, session/token values, пароли или сырые служебные дампы формы.
  • Event Name из dropdown трактуется как допустимый ключ, но backend-trigger и переменные нужно подтвердить отдельно.

Что передавать программисту

  • ZIP-пакет как основной артефакт.
  • TEMPLATES_PREVIEW_RU_EN.html как клиентский просмотр русской и английской версии каждого шаблона.
  • BILINGUAL_UPLOAD_GUIDE_RU.md как правило EN-first загрузки и структура языковых папок.
  • TEMPLATE_SETTINGS_SCENARIOS_RU.html как матрицу "когда / зачем / настройки / backend-гейт".
  • VARIABLES_CONTRACT_RU.html как отдельный список новых/неподтвержденных переменных.
  • CODEX_PROGRAMMER_HANDOFF_RU.md как рабочий контракт для пары программист + Codex.
  • EMAIL_NOTIFICATION_LOGIC_RU.md как разбор Event Name, Condition ID, Delay и рисков backend-trigger.
  • ADMIN_UPLOAD_GUIDE_RU.md как пошаговую инструкцию загрузки.
  • ADMIN_UPLOAD_INDEX_RU_EN.csv как карту template -> language -> event -> condition -> folder.

Публичная ссылка предназначена для интеграционного handoff, не для отправки писем клиентам напрямую.
