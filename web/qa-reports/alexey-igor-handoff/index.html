Как это работает: выбор сохраняется в этом браузере Алексея. Чтобы Игорь увидел ровно выбранный набор в другом браузере, нажми “Сформировать ссылку для Игоря” и отправь ему полученную ссылку. В ссылке зашиты ID выбранных пунктов.

Как смотреть комментарии Игоря: Игорь на своей странице нажимает “Сформировать ссылку с комментариями” и отправляет ее тебе. Если открыть такую ссылку здесь, ниже появится блок “Ответ Игоря” с отметками и комментариями.

Правило: по умолчанию Игорю показываем только actionable FAIL/WARN и один смешанный WARN, где важно не сломать рабочий happy path. PASS можно включать вручную, если нужно дать контекст “это уже работает”.

Ответ Игоря

Источник: данные ниже пришли из ссылки Игоря. Это не общий серверный статус; чтобы закрепить их для всех, нужно перенести итог в отчет или коммит.

Фильтр:

Если ссылку не сформировать, страница Игоря покажет дефолтный набор из реестра. Для постоянного изменения дефолта нужен коммит в qa-handoff-data.js.
