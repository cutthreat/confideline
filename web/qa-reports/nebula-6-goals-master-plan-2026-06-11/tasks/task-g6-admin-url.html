G6.6 Админка на отдельном URL

Команда должна работать через админку напрямую, без привязки к фронту и без входа через клиентский путь.

← Назад к списку задач

Что требуется

P0 · Цель 6: рабочий контур команды · separate admin URL

Результат: супер-админ, агент и эксперт открывают рабочую админку по отдельному адресу и видят только свои задачи, консультации, анкеты, сроки, качество и эскалации.

Кому нужно
  • супер-админу для контроля сервиса;
  • агенту-эксперту для нескольких анкет;
  • эксперту для консультаций и правил работы.
Что должно быть на старте
  • отдельный URL админки;
  • роль и доступ без клиентского фронта;
  • список консультаций и анкет;
  • видимые сроки ответа и эскалации.
PbExpert как ориентир
  • слева очередь диалогов с фильтрами assigned/all и paid/not paid;
  • в центре активный чат и быстрые действия Book Now, Review, Read, Summarize, Polish;
  • справа карточка клиента: баланс, уровень, партнер, лимиты, chat info, user info.
  • Открыть HTML-макет кабинета
Почему это нужно рано
  • через этот кабинет учим кандидатов;
  • через него агент ведет несколько анкет;
  • без него нельзя честно проверить SLA, качество и назначение.
Зависимости
  • карточка консультации;
  • статусы консультации;
  • права ролей;
  • обучение и регламенты.
Критерий приемки
  • команда входит в админку по отдельному адресу;
  • эксперт не проходит клиентский путь;
  • агент видит несколько назначенных анкет;
  • супер-админ видит контрольный контур.
Служебно: это не редизайн фронта и не полноценная CRM. Это первый рабочий контур для пилотной команды.
