# askNebula functional map -> Nebula/Confideline transfer

Дата: 2026-06-11

## Цель

Снять карту публичного функционала askNebula.com и перевести ее в будущую карту нашего сайта Nebula/Confideline. Рабочая гипотеза от Алексея: в 98% случаев логику делаем как у askNebula, но переносим на наш backend, роли и модель поминутных консультаций.

|---|---|---|---|

| Manhattan отдельная сессия | Заблокировано | Manhattan доступен, но task-start заблокирован активным human handoff | blocker: `active_human_handoff_in_progress`, `control_lane_substitution_blocked` |

## Главный вывод

askNebula устроен как не просто сайт с экспертами, а как связка:

1. публичная эзотерическая витрина;
2. SEO-категории консультаций;
3. карточки экспертов с доверием;
4. quiz/onboarding для подбора эксперта;
5. каталог подходящих экспертов;
6. CTA в чат;
7. free minutes / discount / paid per minute;
8. trust, safety, advisor standards, disclaimer, terms;
9. support/FAQ/legal;
10. отдельный вход для клиента и набор экспертов.

Для нас это значит: дизайн нельзя просто натянуть как красивую главную страницу. Нужно сразу проектировать маршрут клиента от интереса до консультации и связать его с backend: эксперт, агент, чат, деньги, support, качество и аналитика.

## Клиентский путь askNebula

1. Клиент попадает на витрину.
2. Видит оффер: free minutes / discount.
3. Видит темы, направления и экспертов.
4. Нажимает `Try now`, `Get Started` или `See more psychics`.
5. Попадает в quiz:
   - gender;
   - topicToDiscuss;
   - typeOfReading;
   - date of birth;
   - matching/processing;
   - expertsCatalogue.
6. Видит подобранных экспертов.
7. Нажимает `Start Free Chat`.
8. Дальше ожидается регистрация/чат/платежная логика.

Для нашего сайта это надо переложить как:

клиент -> витрина -> тема/эксперт -> вопрос -> условия -> карточка консультации -> чат -> минуты/деньги -> support/refund -> отзыв/качество.

## Backend implications

| AskNebula-сигнал | Что нужно в нашем backend |
|---|---|
| Advisor cards with status, rating, reviews, price/min | Таблицы/поля эксперта: статус, направления, рейтинг, отзывы, цена, опыт, доступность |
| Quiz preferences | Хранить параметры подбора: тема, тип чтения, birth data, выбранный эксперт |
| Start Free Chat | Создавать карточку консультации и запускать чат с trial/free minutes |
| Chat for price/min | Поскольку у нас сейчас нет поминутной backend-логики, нужно реализовать timer/balance/stop/accrual |
| FAQ / disclaimer / standards | Дисклеймеры и правила должны быть видны до старта консультации и связаны с refund/support |
| Reviews | Нужны отзывы после консультации и QA-модерация |
| Rewards / bonuses | Можно заложить как P1 после базового запуска денег |

## Marketing implications

| Что делает askNebula | Что делать нам |
|---|---|
| Продает не “чат”, а ясность/поддержку/личное духовное руководство | Формулировать оффер как эзотерическая консультация с живым экспертом |
| Дает free minutes + discount | Нужна стартовая акция: бесплатные минуты/бонус/скидка, если экономика позволяет |
| Использует trust stats: users, psychics, availability, rating | Нам нужны честные trust-блоки: проверенные эксперты, часы доступности, отзывы, количество консультаций после появления данных |
| Использует SEO-страницы под темы | Нужны посадочные под направления и темы до масштабной рекламы |
| Ведет в quiz, а не сразу в оплату | Для холодного трафика лучше quiz/prescreen, чем прямой checkout |

## Что нельзя слепо копировать

1. Числа доверия askNebula нельзя переносить: users, psychics, rating, consultations должны быть нашими.
2. Цена/мин и free minutes зависят от нашей экономики.
3. Claims экспертов должны проходить модерацию.
4. Legal/disclaimer надо адаптировать под юрисдикцию и фактическую модель сервиса.
5. Rewards можно делать позже, не блокирует MVP.

## QA / blockers

| Зона | Статус | Комментарий |
|---|---|---|
| Публичная витрина | PASS | HTML/скриншот сохранены |
| Категории / SEO | PASS частично | Ключевые страницы сняты; часть topic URL из прямой гипотезы дала 404 |
| Expert directory | PASS | `/psychics` ведет на `/expert`; каталог снят |
| Expert profile | PASS | QuickTarot снят отдельным доказательством |
| CTA to quiz | PASS | `Try now`, `Get Started`, `See more psychics` ведут в quiz gender |
| Quiz flow | PASS частично | Дошел до expertsCatalogue; дальше `Start Free Chat` требует отдельного безопасного прохода, вероятно регистрация/аккаунт |
| Manhattan second pass | BLOCKED | Активный human handoff блокирует отдельную сессию |
