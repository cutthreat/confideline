Запрограммировать безопасные переменные в SEO-текстах стран и городов

ТЗ для программиста: публичный рендер стран и городов должен подставлять разрешенные плейсхолдеры из SEO-полей и не показывать пользователю сырой текст вида {{siteName}}.

Результат

На публичных страницах стран и городов плейсхолдеры из SEO-полей должны подставляться автоматически, чтобы в текстах можно было хранить {{siteName}}, а не жестко писать бренд проекта.

Что нужно сделать

  1. Найти место, где публичные страницы страны и города выводят поля Meta Title, Meta Description, H1, Seo Text и Html Description.
  2. Перед выводом этих полей пропускать текст через один общий helper/сервис замены переменных, а не делать разрозненные str_replace в шаблонах.
  3. Поддержать активную переменную {{siteName}}: значение брать из настройки сайта frontend.siteName.
  4. Поддержать {{siteUrl}} только для отдельного URL или href, значение брать из common.siteUrl. В обычные предложения ее не подставлять как текстовую фразу.
  5. Не добавлять inline-переменные для страны, города, типа локации, услуги или формата консультации: они ломают падежи, артикли и согласования в RU/ES/IT/DE/PT.
  6. Заложить расширение под целые локализованные HTML-блоки, но не включать их без отдельного renderer-контракта: {{whatWeOfferBlock}}, {{geoServiceListBlock}}, {{informationalDisclaimerBlock}}.

Как должно работать после фикса

  • Если в SEO-тексте страны или города сохранено {{siteName}}, на публичной странице пользователь видит текущее название проекта, например Neiro.
  • Если значение siteName поменяется в настройках, новые публичные страницы автоматически покажут новое имя без ручной правки 1884 TXT-файлов.
  • В админке можно продолжать хранить исходный SEO-текст с плейсхолдерами; на публичной странице сырой {{siteName}} не должен быть виден.
  • HTML должен остаться безопасным: не добавлять новые разрешенные теги, не экранировать уже разрешенный HTML так, чтобы он стал видимым текстом.

Где смотреть

  • Админка стран: /ru/admin/country, публичные страницы стран.
  • Админка городов: /ru/admin/geoname, публичные страницы городов.
  • Настройка бренда: application/config/settings.php, alias siteName.
  • Карта правил для контента: Confideline/geo-content-production/seo-template-variables.json.

Критерии приемки

  1. На тестовой стране и тестовом городе во всех 6 языках {{siteName}} подставляется в title/meta/H1/SEO/HTML description.
  2. На публичной странице нет сырого текста {{siteName}}, {{siteUrl}} или неизвестных {{...}}.
  3. После временной смены siteName в настройках публичная страница меняет бренд; после rollback возвращается исходное значение.
  4. Названия стран и городов не заменяются переменными и остаются в готовом локализованном тексте.
  5. Ретест фиксируется в QA Control Center: PASS для страны, PASS для города, скрин публичной страницы и ссылка на исходный SEO-текст в админке.
