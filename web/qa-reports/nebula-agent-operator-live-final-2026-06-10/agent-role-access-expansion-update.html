Агент Kristy: рабочий доступ расширен

Цель проверки: дать агенту доступ, достаточный для работы с назначенными анкетами экспертов и клиентскими коммуникациями, без превращения роли в супер-админа.

Управленческий вывод

Готово: роль agent расширена до рабочего минимума: собственная карточка агента, назначенные анкеты, чат, сообщения, поддержка, заказы, транзакции и жалобы доступны под Kristy.

Осталось: общий список всех партнеров /ru/admin/partner/index остается закрыт даже после добавления partners-all. Для операционной работы Kristy это не блокер, потому что карточка Kristy и ее назначенные анкеты открываются. Если нужен именно общий реестр партнеров для агента, требуется отдельное исправление правила доступа в коде/роутинге.

Что это значит для Nebula

Агент уже может быть рабочим оператором нескольких анкет экспертов: видеть свои анкеты, вести коммуникацию, проверять обращения, заказы, транзакции и жалобы. Для запуска эзотерических консультаций все равно нужен отдельный слой service_session: назначение консультации, поминутные лимиты, SLA, начисления эксперту и связь с поддержкой/refund.

Доказательства: изменение роли, проверка под Kristy, обновленный мастер-план.
