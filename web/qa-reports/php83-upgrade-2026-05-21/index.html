Факт

Production QA завершился без таймаута, но итоговый release decision: NO_GO. Из 15 critical steps плохие: runtime-readiness, admin-storage-validation, performance, security, analytics-runtime, full-qa, release-decision, artifact-contract.

Несовпадение версии

Прямые live HEAD-запросы к /, /en, /ru, /en/signup вернули X-Powered-By: PHP/8.5.0. Если целевой перевод был именно на PHP 8.3, нужно проверить конфигурацию PHP-FPM/hosting pool/CDN origin.

Что прошло

Публичный browser smoke desktop/mobile прошел. Базовые маршруты home/login/signup/recovery/legal отдают 200 в full QA. Node, npm, Playwright и локальные source-level PHP lint checks доступны.

Что блокирует

Admin routes в текущем storage state отдают 404, axe WCAG падает на public routes, human desktop journey превышает latency threshold, Docker daemon не готов для k6/ZAP, analytics runtime не доказан.

Факты

  • Публичные маршруты /en, /en/login, /en/signup, recovery и legal pages открываются с 200.
  • Главная /en все еще имеет title Welcome to YouDate!.

  • Локальный source показывает наличие Confideline branding/security/a11y fixes, но live QA их не подтверждает как развернутые.

Вывод

Это не один баг после PHP-обновления, а набор разных контуров: runtime version mismatch, live routing/admin access, live public UI/accessibility, deploy-sync gap, analytics proof gap и локальные performance/security tooling blockers.

Не делать вслепую

  • Не закрывать accessibility/security/brand по source-only proof: live все еще показывает старое поведение.
  • Не ослаблять latency threshold 5000 ms ради зеленого теста.
  • Не коммитить storage-state или секреты после admin-login capture.
  • Не считать analytics schema conversion truth без runtime beacons.
