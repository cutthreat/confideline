Факт

Свежий production QA по live-домену завершился FAIL / NO_GO. После уточнения входа в админку прежний вывод про /ru/admin = 404 переведен в INVALID/RETEST: админку нельзя проверять прямым анонимным заходом.

Клиентская часть

Публичный browser smoke и human-paced customer journey теперь проходят: главная, login/signup формы и базовые legal/trust маршруты открываются на desktop и mobile.

Админка

Правильный flow: сначала login как обычный пользователь с ролью супер-админ/админ, затем вход в админ-панель через выпадающее меню Администрирование или уже авторизованную вкладку /ru/admin. Manhattan evidence показывает живые страницы /ru/admin/geoname/update и /ru/admin/country/update.

Синтаксис

Live-синтаксис напрямую не виден без серверных логов. По live HTTP на публичных маршрутах 500 не найден. Дополнительно локальный source-снимок: php -l прошел по 861 PHP-файлу, 0 syntax errors.
