Решение

ВопросОтвет
Можно ли закрыть 21 gap текущим локальным исходником?Нет. Точечный поиск по контроллерам, route names и view names внутри Confideline не нашел matching source. Эти страницы остаются live-evidence-only.
Это ломает product-аудит?Нет для управленческого мастер-плана: страницы доказаны live скрином/HTML/DOM. Но это блокирует честный claim “каждая строка кода этих страниц изучена”.
Что нужно для полного code audit?Актуальный source snapshot live-админки или отдельный staging/source доступ, после чего повторить source mapping по этим 21 страницам.
