Confideline Analytics Dashboard Spec

Спецификация для backend-интеграции админского dashboard под эзотерические консультации в живом текстовом чате с поминутной оплатой.

Source of truth: `index-admin.php` Активная версия: `v3` Архивные варианты: `v1`, `v2`

Результат

В админке YouDate/Confideline есть рабочая страница dashboard, построенная на существующих admin-компонентах и адаптированная под консультационный продукт, а не под дейтинг.

application/modules/admin/views/default/index-admin.php

Scope

  • Только эзотерические / консультационные услуги.
  • Только живой текстовый чат с поминутной оплатой.
  • Воронка `free -> first paid -> repeat` обязательна.
  • LTV считается отдельным аналитическим слоем, не шагом основной воронки.

Done When

  • Верхний экран отвечает на 4 вопроса: спрос, выход в free, конверсия в первую оплату, повторы.
  • Продуктовый и операционный контуры читаются раздельно.
  • В файле нет dating-логики: likes, matches, gifts, private photos и т.д.
  • Разметка опирается на существующий admin stack: `info-box`, `box`, таблицы, `ChartJs`.

How To Verify

  • Открыть локальную админку: `http://127.0.0.1:8092/admin`.
  • Убедиться, что рендерятся блоки `Дашборд живых консультаций`, `Фильтры и период`, `Потери между free и paid`, `LTV и когорты`.
  • Проверить синтаксис view: `php -l application/modules/admin/views/default/index-admin.php`.
  • Если нужен rollback, сравнить `index-admin.php` с `index-admin-v1.php`.

Основные блоки dashboard

  • Hero с системными статусами и управляемым периодом.
  • Primary KPI: старт бесплатных минут, конверсия в первую оплату, доля повторных оплат, GMV/чистая выручка.
  • Secondary KPI: спрос, принятие, медианный первый ответ, потери между free и paid.
  • Продуктовый контур, воронка, unit-экономика, повторы и выручка, LTV и когорты, драйверы роста, риски и операционка.

Воронка

Просмотр эксперта / каталога → Создан запрос → Принято экспертом → Старт бесплатных минут → Paywall shown → Первая оплаченная минута → Списанные оплаченные минуты → Повторная платная сессия

`LTV D7 / D30 / D90` идут отдельным когортным слоем ниже, а не вставляются внутрь основной продуктовой воронки.
