# Confideline Geo Directory Notes

## Флаги

- Флаги в карточках стран и городов используются только как визуальный ориентир.
- Источник флагов: `/content/themes/youdate/static/images/flags/{countryCode}.svg`.
- В боевой версии флаг лучше выводить через helper по ISO-коду страны, а не хранить inline-style в шаблоне.
- Флаг не должен быть главным `og:image` страницы каталога, страны или города.

## OpenGraph

- Для каталога стран/городов нужен общий брендовый preview image.
- Для страницы страны нужен `og:image` с главным фото страны.
- Для страницы города нужен `og:image` с главным фото города.
- Флаг можно использовать только как вспомогательное изображение внутри интерфейса; для сниппета он слишком слабый и похож на справочник, а не на страницу консультации.

## Пагинация

- На телефоне карточки должны идти по одной в строку.
- На планшете допустимы две карточки в строку.
- На десктопе допустимы три карточки в строку.
- Рекомендуемый размер страницы: 20 элементов.
- В боевой версии пагинация должна иметь реальные URL, например `?page=2`, чтобы поисковые роботы и LLM могли пройти по списку без зависимости от клиентского JS.
- При фильтрации по букве или поиску номер страницы должен сбрасываться на первую.

## Алфавитный фильтр

- На desktop/tablet алфавит выводится кнопками: это быстро считывается и не занимает критичную высоту.
- На мобильной ширине алфавит остается видимыми кнопками, но превращается в горизонтальную ленту с явными стрелками прокрутки.
- Причина: select прячет алфавит и ощущается менее быстрым, а обычная горизонтальная лента на `320px` плохо дает добраться до последней буквы.
- Отдельная кнопка `Все` не нужна: отсутствие выбранной буквы уже означает полный список.
- Клик по букве включает фильтр по этой букве; повторный клик по активной букве сбрасывает фильтр и возвращает полный список.
- Стрелки должны прокручивать ленту примерно на 70% ширины видимой области.
- Неактивная стрелка не показывается: в начале списка скрыта левая стрелка, в конце списка скрыта правая.
- При выборе буквы активная кнопка должна автоматически прокручиваться в видимую область.
- Недоступные буквы скрываются для текущего режима `Страны` или `Города`.
- При смене буквы, режима, поиска или страницы поведение должно быть одинаковым для desktop-кнопок и мобильной ленты.

## Быстрые ссылки на города в карточке страны

- В карточке страны выводится максимум 2 города.
- Карточка страны кликабельна целиком и ведет на страницу страны.
- Отдельная стрелка перехода не выводится: она создавала лишний визуальный шум и прыгала на мобильных карточках.
- Теги городов показываются только там, где карточке реально хватает ширины. На узких карточках они скрываются.
- На mobile теги не выводятся.
- Названия городов в тегах должны быть на текущем языке интерфейса, а не на английском.
- Города выбираются не по алфавиту и не по порядку в базе.
- В быстрые ссылки попадают только города, которые можно безопасно показывать пользователю:
  - `is_active = 1`;
  - страница доступна на текущем языке;
  - заполнены `H1 Hero`, `H2 Hero`, `Teaser Description`, `Html Description`;
  - заполнены SEO-поля `Meta Title` и `Meta Description`;
  - есть `Main Photo` и `Cover Photo`;
  - город относится к текущей стране;
  - страница не скрыта от индексации.
- После фильтра готовности города сортируются по популярности.
- Рекомендуемый порядок приоритета:
  1. ручной `directory_priority`, если редактор задал его в админке;
  2. реальные переходы/просмотры страницы города за последние 90 дней;
  3. количество обращений/регистраций после страницы города, если метрика доступна;
  4. вес узнаваемости города, если метрик еще нет;
  5. алфавит только как последний tie-breaker.
- После сортировки нужно пройти список кандидатов сверху вниз и взять первые города, которые помещаются в тег карточки.
- Если название города слишком длинное для тега, этот город пропускается, а вместо него берется следующий по популярности готовый город.
- Для тега можно использовать отдельное короткое поле `directory_label`; если оно не задано, используется название города на текущем языке.
- Предельная визуальная ширина тега: `92px` на desktop/tablet и `68px` на mobile. На сервере это можно приблизить через whitelist коротких `directory_label`, а на фронте остается страховка по фактической ширине.
- Если у страны есть только 1 готовый город, выводится 1 тег.
- Если готовых городов нет, теги городов не выводятся, остается обычная карточка страны.
- В финальном интерфейсе лучше не показывать обрезанный тег: если label не помещается, он должен быть заменен следующим подходящим городом.

## Контракт для Yii-реализации

Для карточки страны нужен массив `popularCities`, уже отфильтрованный и отсортированный на сервере:

```php
[
    'name' => 'India',
    'translatedName' => 'Индия',
    'url' => '/ru/country/india',
    'citiesUrl' => '/ru/cities?country=IN',
    'flagCode' => 'in',
    'popularCities' => [
        ['name' => 'Дели', 'url' => '/ru/city/in-delhi'],
        ['name' => 'Мумбаи', 'url' => '/ru/city/in-mumbai'],
    ],
]
```

Во view выводить не больше двух элементов `popularCities`. Если тег не помещается, он скрывается фронтовой страховкой, а в боевой версии лучше заранее заменить его следующим коротким популярным городом.

## Карточка города

- Карточка города не должна повторять бейдж `Город`: режим уже задан вкладкой списка.
- В карточке города используется изображение города или подготовленное изображение страны/города из админки, а не флаг страны.
- Изображение отображается через `cover` с фокусом по центру: `background-position: center center`.
- Для отдельных городов можно задавать CSS-переменную `--geo-card-image-position`, если центральный crop не подходит.
- Карточка города кликабельна целиком.
- Отдельная стрелка перехода не выводится.
- В основной текстовой зоне выводятся только:
  - название города на текущем языке;
  - название города на английском или ASCII-форме.
- На `480-639px` карточки города остаются компактными: 2 в ряд, горизонтальная структура, уменьшенное изображение.
- На `320-479px` карточки города идут в 1 ряд.
- Название города может занимать до 2 строк, но карточка не должна раздуваться по высоте.
