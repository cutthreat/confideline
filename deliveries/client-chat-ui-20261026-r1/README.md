# Клиентский чат — комплект для Игоря

Откройте index.html: четыре макета, одно актуальное ТЗ и архив. Все ресурсы макетов находятся в комплекте. Для полного интерактивного пути между страницами используйте публикацию или запустите `node serve.cjs` и откройте адрес из терминала.

- source/ — разметка изменяемых блоков.
- feature/ — изолированные стили; адаптер контейнера отдельно.
- demo/ — только интерактивность примеров, не продуктовые сервисы.
- preview/baseline/ — неизменённые ресурсы сайта для показа; не заменять ими файлы работающего сайта.
- TZ.html — требования и приёмка; TZ.md — тот же документ в редактируемом виде.

Данные тестовые, реальные отправки и платежи не выполняются. Серверные права и запуск сайта этим комплектом не подтверждаются.
