## Контекст И Макросы

У активной записи один `availability_placement`: `pings`, `active_chat` или `paid_chat`. Подпись поля формы `placement` не доказывает имя backend-поля. Placement фильтрует каталог, но не выдаёт права.

- `pings`: разрешённое обращение во вкладке Pings.
- `active_chat`: свободный/предсессионный Chat. Технический контейнер `service_session` для предложения **до согласия клиента** ещё не бизнес-консультация и остаётся здесь.
- `paid_chat`: начатый бизнес-процесс консультации, включая connecting, trial, paid, pause и reconnecting; бесплатный trial также относится сюда. Завершённую сессию исключить.

Игорь показывает соответствие реальных session status + billing mode этому resolver. Не создавать фиктивные persisted states ради названий из документа. Выбор шаблона не запускает сессию, оплату, назначение или отложенные `Needs reply / Assign / Note / Resolve`.

Allowlist уже определён: `{{client_name}}`, `{{expert_name}}`, `{{price_min}}`, `{{trial_min}}`, `{{consult_date}}`, `{{consult_time}}`, `{{timezone}}`, `{{consult_link}}`, `{{topup_link}}`, `{{support_link}}`.

| Макросы | Известная граница из записи 16.08; текущую реализацию ещё проверить |
|---|---|
| `client_name`, `expert_name` | Публичные имена текущего клиента и представляемого профиля; не внутреннее имя оператора/ID/контакт. |

Не повторять миграцию без проверки версии и текущих данных.

## Язык

`AUTO` берёт язык профиля клиента; разрешённый Quality override действует только на диалог. Базовые поля — RU и необязательный EN. При отсутствии EN контракт 14–16.08 сохраняет запись доступной и вставляет утверждённый RU в черновик с отметкой языка/предложением перевести. Предупреждение **не блокирует отдельный ручной Send**; обычные права, цензура и серверные guards обязательны. Новый запрет RU требует отдельного решения, а не скрытой правки #70.

Перевод запускается явно через выбранный Заказчиком DeepL в общем контуре [#58](../references/translation-contract.md). Исходник сохраняется, результат read-only; сбой не подменяет/не отправляет текст автоматически. [Сверка 06.10](../references/translation-reconciliation-20261006.md) нашла уже документированный общий text-only `POST /admin/translation/preview` и `TranslationPreviewService` для реплики и unsent draft. Архивное описание transient local mock — не текущий runtime proof; прогон 07.10 отдельно наблюдал Mock в UI, а не подключённый DeepL. Прежний предложенный DTO существующего `messageId` не является найденным route и не должен быть обязательным для черновика. Игорь подтверждает текущий adapter и подключает разрешённый provider через тот же сервис. Не создавать фиктивное сообщение для получения ID, второй переводчик или ключ во frontend; `internal_comment` не переводится. Наличие admin-only preview не доказывает права клиента/эксперта.
