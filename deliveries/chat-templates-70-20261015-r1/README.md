## Уже согласовано

1. Для любого непустого черновика, включая пробелы и переводы строки, предложить **«Заменить / Добавить в конец / Отмена»**. До явного выбора текст не менять. Выбор шаблона никогда не отправляет сообщение автоматически.
2. «Добавить в конец» сохраняет исходный текст и добавляет шаблон после перевода строки, не удваивая разделитель, если он уже есть. Отмена, Escape, закрытие, ошибка подготовки и запоздалый ответ из другого диалога не должны затирать черновик.
3. Новую кнопку **«Взять себе» не добавлять**. Существующее копирование сохранить; если оно есть, личная копия независима от оригинала. Не добавлять копирование, если его сейчас нет, и не создавать обязательные копии всем операторам.

D70-01 и D70-02 приняты Алексеем 15.10. Повторное согласование этих решений не нужно.

## Что сделать

- Указать текущую сборку/коммит и точные файлы/обработчики уже существующих общей, личной и профильной библиотек, выбора и подготовки текста в Chat V2. Не создавать четвёртую библиотеку.
- Исправить молчаливую замену непустого черновика (R70-01) по согласованным правилам. Сохранить отдельную ручную отправку и обычные серверные ограничения.
- Подтвердить существующие права system / expert profile / personal, привязку к человеку, текущему профилю и диалогу. Прямой чужой ID не должен давать доступ; смена контекста не переносит старый результат в новый диалог.
- Сохранить принятые десять макросов, три placement и RU/EN/AUTO. Значения брать из серверного контекста; неизвестные/недоступные макросы и произвольные URL/HTML не подставлять. Миграцию не запускать повторно без проверки версии.
- Перевод черновика подключать через существующий общий сервис #58 и выбранный DeepL, а не отдельный переводчик. Перевод только по явной команде, read-only, исходник сохраняется; Mock не выдавать за реальный API. Не вводить новый несогласованный запрет ручного Send из-за RU fallback.

Использовать существующую вёрстку. Не добавлять историю версий обычного каталога, специальный template-audit, новые состояния консультации или финансовые операции. Требования платных action-template не смешивать с обычными быстрыми репликами.

## В каком виде вернуть результат

1. Коммит/PR, проверяемую сборку и короткий список изменённых файлов.
2. Таблицу `функция → уже работало / изменено / осталось → файл/обработчик → результат`.
3. Результат существующих сценариев T01–T07 из ТЗ с ролями и тестовыми данными. Для отсутствующего копирования — `NOT_APPLICABLE` с основанием, не фиктивный PASS.
4. Короткую запись сценария защиты черновика: замена, добавление, отмена/ошибка, смена диалога; отдельно подтвердить отсутствие автоотправки. Технические остатки по переводу, правам и сохранению перечислить явно.

Не повторять весь общий аудит: проверить изменённые ветки и необходимую регрессию затронутого поведения на разрешённой сборке.

## Границы комплекта

ТЗ соответствует редакции 15.10 с принятыми D70-01/D70-02. Подготовка этой выдачи не подтверждает исправление R70-01, реальный DeepL, серверные права, persistence или приёмку всей карточки. Старые наблюдения в ТЗ сохраняют свои даты; в этой работе они не повторялись.

Включён **один существующий исходный макет Chat V2 Stage 1 от 04.08** с селектором шаблонов и его ресурсами. Это основание вёрстки, а не демонстрация исполнения новых решений 15.10. При расхождении старых подсказок/заглушек с актуальным ТЗ приоритет у ТЗ. Платные offer/pause шаблоны в этом общем макете — отдельный контур, не новый объём #70. Отдельные экраны трёх библиотек заново не рисовались.

Существующие библиотеки на рабочем сайте, требующие авторизации: [общая](https://confideline.com/ru/admin/chat-message-template/index), [личная](https://confideline.com/ru/admin/chat-personal-message-template/index), [профильная](https://confideline.com/ru/admin/chat-expert-message-template/index). Эти ссылки приведены для привязки, не являются новым live-тестом.

Макет открывается без сборки; внешний вид, CSS/JS и остальные ресурсы сохранены. Из публичной копии HTML удалён только невидимый служебный CSRF-маркер исходника; это очистка поставки, не изменение интерфейса. Документные ссылки адаптированы для переносимости, внутренние исторические proof-ссылки обозначены текстом. Старые редакции ТЗ и внутренние runtime-дампы в комплект не добавлены. Источники августа приведены только как основания; позднее решение Алексея и актуальное ТЗ имеют приоритет.
