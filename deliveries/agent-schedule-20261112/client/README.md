# Запись к экспертам одного агента

Откройте [каталог](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/client/index.html) и [график агента](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/admin/partner.html#schedule) с одного адреса и в одном браузере. Алиса и Вера в демонстрационном примере закреплены за одним агентом.

1. Выберите свободное время у Алисы и отправьте заявку. Заявка появится в разделе «Записи» агента.
2. Откройте выбор времени у Веры: занятый интервал уже недоступен.
3. Откройте заявку Алисы и отмените её: время снова станет доступным у обеих анкет.
4. Измените график агента и отправьте его на согласование. После утверждения администратором свободные окна изменятся у обеих анкет; уже созданные записи сохраняются.

В примере рабочее время 09:00–18:00, а интервал планирования — 30 минут. Это учебные значения. Длительность консультации интервалом планирования не ограничивается. Макеты используют общее локальное состояние браузера; реальных записей и платежей не создают.

В сценарии `index.html?scenario=two-bookings&reset=1` показаны две подтверждённые записи одной пары, выбор конкретной встречи и отправка запроса на досрочное начало. Подтверждение второй стороной, реальный запуск и расчёты макет не воспроизводит: эти действия проверяются после реализации по ТЗ. После отмены в соседнем окне агента демонстрируется результат для выбранной записи.
