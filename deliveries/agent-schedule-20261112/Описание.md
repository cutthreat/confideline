# Запись на консультацию: календарь и график агента

**ТЗ для обсуждения:** [Google Документ](https://docs.google.com/document/d/1TtU7FU3KrjD9I8Dxin3iAiN0N5nwxp89aE7XdiK1zFI/edit). Обновлено 14 ноября 2026 года.

Агент задаёт один рабочий график для всех закреплённых экспертных анкет. Заявка через любую из них удерживает пересекающееся время для всех остальных анкет агента. Изменение графика не отменяет уже принятые заявки или встречи; конфликт показывается ответственным.

Макеты работают с общими демонстрационными данными браузера. Запись у Алисы удерживает время у Веры; отмена освобождает его. Промежуток 30 минут — пример планового окна, а не ограничение длительности платной консультации. У занятого эксперта из окна «Уведомить меня» можно перейти к записи на другое время без обязательной подписки.

Для разработчика: [состояния и права](Переходы.md), `ТЗ.md`, `Проверки.md`, `Примеры уведомлений.md`, исходники экранов в `client`, `admin`, `settings-mockup`. Для автономного запуска из корня комплекта достаточно одного HTTP-сервера; все экраны должны иметь один origin. Макет не подтверждает работу серверной конкурентной защиты, ролей, расчётов и доставки уведомлений.

При текущей консультации обычное снятие назначения и передача откладываются до её завершения; для срочного отзыва доступа предусмотрено отдельное действие уполномоченного администратора с фиксацией причины. При конфликте приоритет — сохранить выбранную анкету, время и цену; если встреча затронута, клиенту предлагают ждать без списаний, перенести встречу с его согласия или отменить её с возвратом неиспользованного аванса. При отмене клиентом и достоверном результате оплаты известный неиспользованный аванс возвращается сразу; при неопределённости возврат проводится после сверки, клиент видит статус обработки. При отсутствии ответа и несостоявшейся встрече по вине площадки сотрудник проверяет оказание услуги и состояние оплаты, после чего неиспользованный аванс возвращается без штрафа.

Агенту начисляется вознаграждение только за фактически проведённую платную часть. Если консультация не состоялась, удержанный с клиента аванс не создаёт вознаграждения агенту; отмена по вине агента рассматривается индивидуально. Перед реализацией проверить действующий код, финансовые операции и полномочия и сверить интеграцию с задачами 1 и 3. Макет не подтверждает, что эти действия уже реализованы на сервере.

При оплате на границе срока учитывается зафиксированный сервером исход: позднее ошибочное списание аванса возвращается клиенту в кредитах. Для перенесённой встречи сроки отмены считаются от нового подтверждённого времени; при переносе по причине площадки до новой встречи возврат неиспользованного аванса полный. Детали и проверки — в ТЗ.
