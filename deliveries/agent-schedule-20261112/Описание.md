# Запись на консультацию: календарь и график агента

**ТЗ для обсуждения:** [Google Документ](https://docs.google.com/document/d/1TtU7FU3KrjD9I8Dxin3iAiN0N5nwxp89aE7XdiK1zFI/edit). Редакция от 12 ноября 2026 года.

Агент задаёт один рабочий график для всех закреплённых экспертных анкет. Заявка через любую из них удерживает пересекающееся время для всех остальных анкет агента. Изменение графика не отменяет уже принятые заявки или встречи; конфликт показывается ответственным.

## Макеты

- [Клиент: выбор времени](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/client/index.html).
- [Агент: рабочий график](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/admin/partner.html#schedule) и [общий журнал записей](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/admin/partner.html#bookings).
- [Записи конкретной анкеты](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/admin/index.html#bookings).
- [Настройки уведомлений клиента](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/settings-mockup/client-channels.html).

Макеты работают с общими демонстрационными данными браузера. Запись у Алисы удерживает время у Веры; отмена освобождает его. Промежуток 30 минут — пример планового окна, а не ограничение длительности платной консультации. Состав кнопок у занятого эксперта в этом примере показан для проверки механики и не утверждает изменение стандартных настроек из задачи 3.
