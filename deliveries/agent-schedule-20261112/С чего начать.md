# С чего начать

**ТЗ для обсуждения.** Финансовые вопросы согласуются отдельно. Сценарии графика и разового переноса описаны в ТЗ и проверках; ранее принятые условия клиента сохраняются.

1. Прочитать [ТЗ по чату](https://docs.google.com/document/d/1sLKIV2xUy6Lk_ER1Nksm4eGGLP34YB1tx2MYfyXg4RQ/edit), [ТЗ по записи](https://docs.google.com/document/d/1TtU7FU3KrjD9I8Dxin3iAiN0N5nwxp89aE7XdiK1zFI/edit) и [ТЗ по настройкам](https://docs.google.com/document/d/18HSTZvkFnRUKOTcrbttiz_dX_0IEFGqaVcJKG4YTouc/edit). Это основные документы; DOCX внутри архива — их копии. При расхождении уточнить и исправить комплект.
2. Открыть клиентский календарь, график агента, его согласование администратором и журнал по ссылкам в «Описание.md».
3. Открыть [макет кнопок](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/settings-mockup/expert-buttons.html), [макет параметров записи](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/settings-mockup/paid-chat.html) и [таблицу параметров](Настройки.md).
4. Использовать «Проверки.md» для приёмки после реализации; тексты сообщений — в «Примеры уведомлений.md».

Макет показывает числовой предел 0–10 на существующей странице настроек чата. Один график действует для всех анкет одного агента. Агент отправляет недели на согласование; после временной остановки запись открывается только на повторно утверждённые недели. Макет не заменяет проверку конкурирующих заявок, ролей, платежей и доставки уведомлений на сервере.
