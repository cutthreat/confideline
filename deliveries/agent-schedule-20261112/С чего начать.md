# С чего начать

1. Прочитать [ТЗ в Google Документе](https://docs.google.com/document/d/1TtU7FU3KrjD9I8Dxin3iAiN0N5nwxp89aE7XdiK1zFI/edit).
2. Открыть клиентский календарь, график и журнал агента по ссылкам в «Описание.md».
3. Прочитать [ТЗ по настройкам](https://docs.google.com/document/d/18HSTZvkFnRUKOTcrbttiz_dX_0IEFGqaVcJKG4YTouc/edit) и открыть [макет кнопок](settings-mockup/expert-buttons.html), [макет параметров записи](settings-mockup/paid-chat.html) и [таблицу параметров](Настройки.md).
4. Использовать «Проверки.md» для приёмки после реализации; тексты сообщений — в «Примеры уведомлений.md».

Один график действует для всех анкет одного агента. Макет не заменяет проверку конкурирующих заявок, ролей, платежей и доставки уведомлений на сервере.
