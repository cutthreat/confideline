# Макет настроек Confideline

Обновлено 12 ноября 2026. Это локальный интерактивный макет для обсуждения, а не действующая админка. Его формы сохраняют примеры только в локальном браузере; изменения не передаются на Confideline.

- `paid-chat.html` показывает существующую страницу «Настройки чата» и предложенные в ней параметры платной консультации, записи и уведомлений. При отключении на учебных данных показывается переходное состояние с примерами обязательств.
- Сценарий без обязательств: `paid-chat.html?obligations=0`. Если снять флажок и сохранить, показано состояние «Выключен»; это лишь второй набор учебных данных.
- `expert-buttons.html` показывает существующую страницу «Общие настройки → Каталог экспертов» с настройкой действия и показа кнопок. Состав карточки клиента не меняется.
- `client-channels.html` повторяет существующую клиентскую страницу `/ru/settings/notifications`: сохранены её навигация и десять прежних флажков, добавлены предлагаемые настройки записей и уведомления об освобождении. Макет сохраняет флажки только в браузере.
- Системные события записи в связанном чате обязательны. Администратор разрешает, а клиент выбирает дополнительные уведомления сайта и письма; в локальном макете выборы сохраняются только в браузере.
- `booking-channels.html` сохраняет старую ссылку и переводит в раздел записи существующей формы чата; отдельного пункта админки нет.
- Для совместной проверки уведомлений открывайте клиентский макет и эти настройки с одного адреса сайта. Между локальными макетами передаются только учебные значения разрешённых и выбранных способов. Реальную подписку и доставку макет не выполняет.

Основа административных форм и клиентской страницы взята с действующего сайта только для чтения; в копии отсутствуют скрытые поля и секреты. Новые стили ограничены компонентами макета, исходные стили проекта не менялись.

На сайте подтверждён общий раздел «Языки» и строка `app / Start chat / Начать чат`. В примере для независимого управления подписями предложены отдельные строки категории `expert_profile_buttons`. Они не добавлены на сайт; ссылки поиска этих новых строк будут давать пустой результат до внедрения. Переходы к действующему разделу языков только открывают его: сохранение переводов на сайте не выполнялось.

Исходы сетевых запросов, серверные права, оплата, фактическая доставка уведомлений и поддержка предложенной категории на действующей сборке этим макетом не проверены. Точные рабочие правила и проверки приведены в ТЗ задачи 3.
