# Задача 3. Настройки платного чата, кнопок и записи

Предварительная задача для обсуждения. Администратору нужны общие настройки платной консультации, записи и кнопок анкеты с переводами через существующий словарь.

**Что нужно сделать:** встроить переключатель и управляемые параметры графика, оплаты, отмены, переноса и выплат в существующие настройки чата, кнопки — в существующую страницу каталога экспертов, а личный выбор каналов — в существующую страницу уведомлений клиента. Сохранить прежние формы и глобальное меню. Подписи кнопок связать с общим словарём; русская подпись меняется в форме, остальные переводы — в существующем словаре.

**Как проверить:** открыть обе действующие страницы до и после доработки; проверить старые поля, включение платного чата, обязательства, одно независимое действие и текст для каждого состояния, общий словарь и два языка, цены, права и каналы. Полные сценарии — в файле «Проверки.md».

**ТЗ:** [Google Документ](https://docs.google.com/document/d/18HSTZvkFnRUKOTcrbttiz_dX_0IEFGqaVcJKG4YTouc/edit); копия — «ТЗ.docx».

**Макеты:** [настройки записи](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/settings-mockup/paid-chat.html), [действия анкет](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/settings-mockup/expert-buttons.html), [уведомления клиента](https://cutthreat.github.io/confideline/deliveries/agent-schedule-20261112/settings-mockup/client-channels.html). Это демонстрация, а не функционал сайта.

Единый график задаёт агент; его используют все назначенные экспертные анкеты. Новые параметры применяются к новым заявкам, условия действующих заявок сохраняются. Выплаты использовать по действующей схеме за фактическую платную часть; отмены по вине агента рассматриваются индивидуально.
