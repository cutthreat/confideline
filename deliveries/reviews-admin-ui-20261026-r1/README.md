# Отзывы: макеты для Игоря

Актуальная редакция: 26 октября 2026 года. Открыть `index.html`: три HTML-макета, одно ТЗ и архив.

- `reviews.html` — список и модерация отзывов.
- `write-review.html` — создание отзыва; рейтинг эксперта только для чтения.
- `settings.html` — **Настройки → Общие настройки → Отзывы**. Реестр экспертов с обоими вариантами рейтинга и итогом. Три режима: индивидуально, всем по опубликованным оценкам, всем с базой. В общих режимах персональное редактирование заблокировано; сохранённые значения не стираются. Политика, настройка эксперта и параметры публикации сохраняются независимо.
- `TZ.html` — задача, поведение, права, границы вёрстки и критерии приёмки.

Девять исходных CSS админки, шапка, логотип и оформление бокового меню не менялись. Новые CSS ограничены `#confideline-reviews`; `content/` и `external/` — замороженные ресурсы для показа, их не нужно повторно внедрять поверх сайта. Меняется только положение настроек отзывов в существующей навигации.

`feature/` содержит адаптеры интерфейса. `demo/` — локальная демонстрационная модель и сценарии, не backend и не схема его подключения. Подключение к сайту определяет Игорь. Формула рейтинга и действующая логика модерации сохранены; добавлена политика расчёта без перезаписи базы. Отдельной галочки участия отзыва в рейтинге нет: опубликованная оценка учитывается автоматически. Данные синтетические; действия не меняют confideline.com.

Для локального показа достаточно статического HTTP-сервера. Параметры `role=moderator` / `role=superadmin` и `lang=ru` / `lang=en` переключают демонстрационный контекст, не выполняют авторизацию.

В архив не включены промежуточные редакции, скриншоты проверок, журналы и инструменты сборки. Требования и критерии приёмки собраны в одном `TZ.html`.
