## A-FIN-01 — P2: поля дат перекрывают соседние фильтры партнёров

**Страница и состояние:** `preview/finance/partner.html`, мобильная ширина 390 CSS px, горизонтальная прокрутка к «Последний вход» / «Последняя операция» / «Последняя выплата».

**Наблюдение:** каждая ячейка даты имеет ширину 120 px, а мобильная обёртка поля требует минимум 140 px. С учётом отступов поле заходит на следующее поле на 20 px. Например, в исходном `BROWSER-REVIEW.json` рамка «Дата последнего входа» занимает x=419,5625…559,5625, а фильтр текущего плана начинается уже с x=539,5625. Такой же 20 px конфликт есть между «Последняя операция» / «Последняя выплата» и «Последняя выплата» / «Статус блокировки».

**Последствие:** соседние рамки сливаются, правая часть поля даты и её зона очистки оказываются в области следующего фильтра. Равная высота и одна вертикальная ось фильтров не выявляют это горизонтальное пересечение.

**Доказательства:**

- Исходные измерения: `../20261026-finance-full-handoff-check/BROWSER-REVIEW.json`, объект `partner`, `viewport: 390`.
- Визуальное подтверждение до: `evidence/partner-overlap-before.png`.
- Причина: исходный `preview/assets/content/assets/f0c49788/partner_custom.css:1–7` задаёт date-cell 120 px; `preview/assets/content/assets/38c24d7b/css/financial-adapter.css:68–70` задаёт мобильной `.finance-date-filter[data-finance-date-mode="single"]` минимум 140 px. DOM фильтров: `preview/finance/partner.html:211`.

**Минимальное исправление:** отдельный `package/integration/partner-date-columns.css` расширяет только `.finance-partners #partners-finance-grid .grid-date-cell` до 152 px при `max-width:767px`. 152 = существующее поле 140 + два отступа по 6. Исходные CSS не требуется переписывать; полные подписи партнёров и desktop-геометрия сохраняются. Выбранное число получено из местной геометрии, а не из универсального норматива дизайн-системы.

**Проверка исправления:**

- Reviewer прочитал весь новый CSS: один media query, один селектор внутри таблицы партнёров, три свойства ширины; правил оболочки нет.
- Сопоставлены `evidence/partner-overlap-before.png` и `evidence/partner-overlap-after.png`: рамки разделены, полный заголовок сохранён.
- `LAYOUT-MATRIX.json`: 54 из 54 измеренных видимых контролов помещаются в свои ячейки на 360 / 390 / 767 / 768 / 1024 / 1440 CSS px; общий горизонтальный overflow отсутствует. Даты: 152 px на первых трёх ширинах, прежние 120 px на остальных.
- `ACTIVE-STATES.json`: выбор 17.10.2026 оставляет строку 3; сброс возвращает строки 1–5 и пустое поле. Измеренные контролы остаются внутри ячеек в обоих состояниях.

**Статус:** FIXED_AND_REVIEWED в локальном пакете текущего прохода. Публикацию и соответствие ZIP проверяет основной исполнитель отдельно.
