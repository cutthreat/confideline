# Баланс — комплект Игорю r5

## R5 — общая ось финансовых фильтров

В строке фильтров «Операций баланса» и «Моего баланса» обёртка Kartik RangeInput наследовала margin-bottom15px от Bootstrap form-group. Пустой help-block дополнительно сохранял margin5/10px. Из-за центрирования table-cell рамки суммы были выше остальных на7.5px; простое обнуление первого отступа оставляло5px.

Подключить отдельно integration/finance-field-range.css после существующих CSS только для этих двух grid. Два правила ограничены #finance-ledger-grid/#finance-my-balance-grid и строкой .filters. Обнулён только отступ группы; скрывается только пустой help-block. Непустые сообщения об ошибках остаются видимыми. Нет отрицательных смещений, новой высоты/шрифта, global reset или изменения исходных файлов заказчика. На текущем сайте исходный отступ также воспроизведён; применимость адаптера при интеграции проверить в его существующем cascade и не дублировать уже исправленный эквивалент.

Исходные25CSS сохранены побайтно. Новых контроллеров/правил фильтрации нет. Формы, даты, query keys, значения, сортировка и разметка r4 сохраняются. Ширина/высота выбранных multiple-типов может расти штатно; сравнивать центры видимых рамок. Одинаковая CSS-height сама по себе не подтверждает выравнивание.
