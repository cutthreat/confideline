Отдельная страница сохранена по прямому поручению Алексея. Восемь интерактивных страниц финансового контура, связанные состояния, RU/EN-заголовки, файлы/инструкции/приёмка. Партнёры — неизменённый эталон. Цензура и взаимодействия не включены. Боевой сайт не изменён; финансовая и серверная приёмка отдельно.

Локально: распаковать ZIP, выполнить из его папки `python -m http.server 8765 --bind 127.0.0.1`, открыть http://127.0.0.1:8765/index.html. Интерактивно использовать Pages/HTTP; GitHub отображает HTML как код. Данные синтетические; EN относится только к согласованным заголовкам.
