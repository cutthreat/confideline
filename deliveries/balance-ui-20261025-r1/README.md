# Баланс — исправленный комплект Игорю r2

r1 ошибочно подменил доработанные «Мои выплаты» обычной страницей. В r2 восстановлен исходный красивый компонент: карточка баланса/запроса, отдельная панель истории, бейджи, карточка и реквизиты. Эталон — доработанная finance-headings-v6, с сохранением последующих коротких заголовков и общего периода. Отдельная страница сохраняется. Текущая синяя оболочка сайта не изменена.

Восьмёрка финансовых страниц сохранена; изменения r2 касаются только трёх экранов выплат и их комплекта. В preview фиксированные данные, не production. Для локального просмотра выполнить `python -m http.server 8765 --bind 127.0.0.1` и открыть http://127.0.0.1:8765/index.html. Старый URL архива r1 также отдаёт исправленные байты r2.
