# Codex: Выдача и карточки

Пакет передачи 02.11.2026, редакция подачи r2. Продуктовые требования не изменены. Основное задание: [ТЗ для человека](TZ.html), текстовая копия [TZ.md](TZ.md). Инструкция производная, не заменяет ТЗ и не добавляет требований.

## Поручение

Реализовать задачу «Выдача и карточки» по приложенному ТЗ в целевом репозитории. Сначала прочитать его AGENTS и проверить текущую реализацию. Папка этого комплекта содержит макеты и примеры, а не сам рабочий backend.

Представление выдачи, карточки, действия, все существующие точки входа в бесплатный чат и настройка карточек. Параметры поиска, доступность, счётчик и страницы принадлежат соседней задаче.

## Порядок работы

1. Прочитать TZ.html с иллюстрациями и TZ.md целиком, включая границы, состояния и приёмку. Если файлы разных редакций или обнаружено противоречие, зафиксировать его и не выбирать удобную трактовку молча.
2. Найти действующие маршруты, серверные проверки, шаблоны v1, настройки, данные и тесты в целевом приложении. Сопоставить с [интеграцией](../integration/README.md); примеры [integration/cards](../integration/cards/) адаптировать, не копировать как готовый backend. Имена таблиц, permission и API не предписаны этим пакетом.
3. Сохранить существующий v1, историю, данные и соседний выбор настройки. Реализовать только свою область из ТЗ. Общая логика двух задач должна быть внедрена и проверена до заявления о готовности любого сочетания версий; независимость оформления не отменяет общей логики.
4. Проверить каждый из 14 критериев ниже на реализации. Заполнить копию acceptance.xlsx фактическими результатами и доказательствами; исходные NOT_RUN не превращать в PASS по наличию макета или исходников. Запустить штатные проверки целевого репозитория.
5. Передать изменённые файлы, результаты по тем же ID, снимки существенных состояний и непроверенные пункты. Не выдавать локальную демонстрацию за серверную приёмку. Публикация, production deploy, миграция данных и реальные платёжные действия не разрешены одним наличием этого пакета; соблюдать отдельное поручение владельца.

| C05 | Во время входа online стал busy/offline либо профиль закрыт | В первом случае диалог с актуальным статусом; во втором безопасный отказ |

| C08 | Открыть чат, отправить бесплатное сообщение, согласиться на предложение без Start | Баланс/начисления/таймер не меняются до отдельного разрешённого платного запуска |
