# С чего начать

Две самостоятельные задачи для Игоря. Открыть index.html: в каждой задаче есть макет и полное ТЗ для человека.

- filter/TZ.html или TZ.docx — фильтр, условия поиска и его настройка.
- results/TZ.html или TZ.docx — выдача, карточки, все существующие входы в бесплатный чат и настройка карточек.
- admin.html — проектируемый подраздел «Каталог экспертов» в оболочке действующей админки.
- CODEX.html в папке каждой задачи — читаемая производная инструкция агенту; CODEX.md — текстовая копия.
- acceptance.xlsx — 14 понятных проверок каждой задачи и отдельный лист технических кодов. Проверки внедрения ещё не выполнялись.
- integration/ — раздельные блоки для адаптации в рабочем приложении; demo/ — искусственные данные и локальные действия.

HTML ТЗ автономны, с изображениями внутри. Word/PDF — та же редакция. Для понимания каждой задачи не нужны история чата и соседнее ТЗ. Прежние материалы в legacy-reference — только история, не альтернативное задание.

Рабочие настройки сайта не менялись. Макет не реализует серверный поиск, авторизацию, доставку сообщений или платный старт. Новый фильтр и карточки включаются независимо, прежние рабочие варианты сохраняются. Пределы проверки и независимой вычитки — REVIEW.md.
