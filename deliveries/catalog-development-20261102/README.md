# С чего начать

Редакция 03.11.2026, r13. Откройте index.html в обычном браузере и выберите задачу. Встроенный просмотр отдельного HTML-файла может не загрузить скрипты и соседние ресурсы. В каждой задаче доступны макет, ТЗ и инструкция для Codex. Переключатель RU/EN относится к макетам.

- `filter/TZ.html` — фильтр каталога.
- `results/TZ.html` — выдача анкет и переход в существующий чат.
- `integration/` — примеры подключения к действующему приложению.

Макеты содержат искусственные данные и не подключены к рабочему серверу. Критерии внутри ТЗ предназначены для проверки после внедрения.
