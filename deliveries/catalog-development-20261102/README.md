# С чего начать

Редакция 02.11.2026. Две независимые задачи для Игоря.

## Для человека

Открыть index.html: выбрать задачу, посмотреть макет и прочитать её ТЗ. Основные документы — filter/TZ.html и results/TZ.html; Word и PDF являются экспортами этих же требований.

## Для агента Codex

Для фильтра начать с filter/CODEX.md, для карточек — с results/CODEX.md. Эти инструкции производные от соответствующего ТЗ и содержат те же критерии, без новых продуктовых решений. Связь файлов и хешей: handoff-consistency.json. Соседняя задача приложена как справка о границах, не как поручение выполнить обе сразу. Сам комплект не разрешает deploy рабочего сайта.

## Состав и границы

1. filter/TZ.html или TZ.docx: фильтр и его настройка.
2. results/TZ.html или TZ.docx: выдача, карточки, переходы в бесплатный чат и отдельная настройка.
3. demo/catalog-filter.html и demo/catalog-filter-auth.html: актуальные интерактивные макеты на искусственных данных.
4. admin.html: локальная демонстрация двух независимых настроек.
5. integration/: переносимые блоки, раздельные AssetBundle и пример выбора версий.
6. filter/acceptance.xlsx и results/acceptance.xlsx: редактируемые ожидаемые проверки. Серверные пункты не выполнены.
7. sources/: основания логики, соответствие старых и новых требований. legacy-reference/: неизменённая история, не актуальные требования.

HTML открывается локально без установки. Макет не подключён к сайту, не авторизует и не отправляет реальные сообщения. Нельзя переносить demo-контроллер вместо рабочего приложения.

Прежний текущий сайт v1 сохраняется в приложении Игоря. В архиве есть предыдущая опубликованная поставка, а не выдуманная копия серверного v1. Четыре сочетания описаны и включены в приёмку; их работа на сервере ещё не проверена.

Текущий источник: два ТЗ этой редакции. DOCX и HTML получены из одного Markdown; отдельного облачного документа этой редакции не создано. Статус независимого согласования и проверки указан в REVIEW.md.
