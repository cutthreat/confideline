## Сохранение номеров

F01–F12 и F14 относятся к фильтру; F13, F15–F18 относятся к выдаче и карточкам. F07/F11 уточнены поздним правилом гостям online-only. C01–C08 добавляют явные сценарии карточек и бесплатного чата. S01/S02 описывают две независимые настройки. Старые пункты не признаны пройденными и не удалены.

## Предметные источники

- G3.3 «Профиль эксперта», разделы 9–10: доступен/занят/офлайн, бесплатный диалог, auth, один постоянный диалог пары клиент+эксперт, без автоматической оплаты.
- G3.4 «Подбор и старт», разделы 9–12: бесплатный вопрос, сохранение намерения после входа, нет платной очереди/асинхронной платной консультации MVP.
- G3.2 «Каталог», разделы 10–12: доступность, карточка и переход.
- G3 owner answers 18.08.2026 и карта продукта Nebula: request/offer, согласие клиента, отдельный Start оператора; само согласие не включает часы.
- Статическая вёрстка psychics.html использует Start chat / Book session / Chat; её JS возвращает backendRequired, sessionCreated:false, paymentStarted:false. Нельзя переносить подпись Book session как подтверждённое бронирование.

Копии точных предметных разделов находятся рядом в source-excerpts.md. Они не доказывают реализацию на сайте.

## UX-основание

Сохранены проектная панель и карточка. Carbon Modal / Universal behaviors и Overflow content, проверено 02.11.2026: удержание фокуса внутри, доступное закрытие, прокрутка содержимого без горизонтального скролла. https://www.carbondesignsystem.com/building-blocks/core/components/modal/guidelines
