# Разбор независимой вычитки

Первый законченный ответ получен 02.11.2026. Читатель видел оба DOCX и все семь встроенных изображений без истории проекта. Вердикты: человеку понятно; технически не полностью однозначно до уточнений. Это проверка документов, не сайта. Полный ответ сохранён в readback-round1.txt.

| Замечание | Решение и основание |
| --- | --- |
| Одно поле из двух окон можно молча перезаписать | Подтверждено. В S01 и S02 отдельно определены независимая запись разных полей и обнаружение конфликта одного поля; критерии согласованы. Это уточнение уже требовавшегося запрета молчаливой перезаписи. |
| Старый параметр в v2 можно применить скрыто либо проигнорировать | Подтверждено. F01/F05 сохраняют прежнюю серверную семантику и явно показывают такое условие с прежним названием. Снятие/сброс только явные; сохранённые предпочтения не затираются просмотром. Основание: прежнее ТЗ требует работающих старых ссылок без незаметного изменения смысла. Новая тема вместо старого поля не изобретается. |
| Не определены страница после снятия условия и исчезнувшая страница | Подтверждено. Снятие ведёт на страницу 1; номер сверх диапазона приводится к последнему существующему, при пустоте внутренний номер 1 и нет пагинации. Это соответствует уже существующей логике model.paginate и изменения условий в исходном макете. |
| Независимость интерфейсов смешана с общей серверной логикой | Подтверждено. В обоих ТЗ названы владельцы: отбор/счётчик в задаче 1, общий чат в задаче 2. Общие части обязательны до признания сочетания полностью внедрённым; их можно поставить при v1/v1. Независимы включение и ресурсы двух оформлений, не права и бесплатность чата. |
| Одна карточка: 300 px или ширина ленты | Подтверждено. Единственная карточка прямо объявлена исключением, на всю ширину. Так работает сохранённое правило :only-child; добавлена отдельная проверка 480 px. |
| Неизвестный статус у клиента | Подтверждён пробел. Каталог включает только подтверждённые online/busy/offline; неизвестный исключён до подсчёта для обеих ролей, без удаления профиля/истории. Добавлена проверка демонстрационной политики. |
| URL при ошибке поиска | Подтверждён пробел. F06 описывает фиксацию применённого запроса до ожидания, сохранение его при ошибке, отсутствие ложной старой выдачи и лишней записи истории при повторе. Соответствует существующему filter.js. |
| Номер перекрывает заголовок, обрезан верх бейджа, не видна галочка | Подтверждено. Исходные снимки не закрашиваются. Новые аннотации отрендерены вокруг отдельных снимков, номер вынесен наружу; карточка снята с верхним запасом, у фильтра выбран Astrology. |
| Нумерация рисунков не самостоятельна, синий контур непонятен | Подтверждено. В каждом ТЗ собственная последовательность; подписи отличают красную редакционную рамку от штатного синего клавиатурного фокуса. |
| Исходники и выдержки не проверены внешним читателем | Предел вычитки, не дефект. Читателю передавались два DOCX. Исходники, источники и локальные проверки входят в основной комплект; независимая серверная приёмка не заявлена. |

Основной ожидаемый смысл совпал: роли, OR/AND, черновик и отмена, один диалог выбранного эксперта, вход с сохранением намерения, free chat отдельно от платного Start, два независимых выбора, сохранение v1, отсутствие нового бронирования. Новых продуктовых функций по предложению читателя не добавляли.
