# Codex: Фильтр каталога

Пакет передачи 02.11.2026, редакция подачи r2. Продуктовые требования не изменены. Основное задание: [ТЗ для человека](TZ.html), текстовая копия [TZ.md](TZ.md). Инструкция производная, не заменяет ТЗ и не добавляет требований.

## Поручение

Реализовать задачу «Фильтр каталога» по приложенному ТЗ в целевом репозитории. Сначала прочитать его AGENTS и проверить текущую реализацию. Папка этого комплекта содержит макеты и примеры, а не сам рабочий backend.

Параметры поиска, доступность экспертов, счётчик, страницы, сохранение условий и настройка фильтра. Оформление карточек и общий вход в чат принадлежат соседней задаче.

## Порядок работы

1. Прочитать TZ.html с иллюстрациями и TZ.md целиком, включая границы, состояния и приёмку. Если файлы разных редакций или обнаружено противоречие, зафиксировать его и не выбирать удобную трактовку молча.
2. Найти действующие маршруты, серверные проверки, шаблоны v1, настройки, данные и тесты в целевом приложении. Сопоставить с [интеграцией](../integration/README.md); примеры [integration/filter](../integration/filter/) адаптировать, не копировать как готовый backend. Имена таблиц, permission и API не предписаны этим пакетом.
3. Сохранить существующий v1, историю, данные и соседний выбор настройки. Реализовать только свою область из ТЗ. Общая логика двух задач должна быть внедрена и проверена до заявления о готовности любого сочетания версий; независимость оформления не отменяет общей логики.
4. Проверить каждый из 14 критериев ниже на реализации. Заполнить копию acceptance.xlsx фактическими результатами и доказательствами; исходные NOT_RUN не превращать в PASS по наличию макета или исходников. Запустить штатные проверки целевого репозитория.
5. Передать изменённые файлы, результаты по тем же ID, снимки существенных состояний и непроверенные пункты. Не выдавать локальную демонстрацию за серверную приёмку. Публикация, production deploy, миграция данных и реальные платёжные действия не разрешены одним наличием этого пакета; соблюдать отдельное поручение владельца.

## Приёмка задачи 1

| ID | Условия и действие | Ожидаемый результат |
| --- | --- | --- |
| F01 | Открыть прежнюю ссылку с параметром вне 11 опций; переключить v1/v2/v1; снять условие и сбросить | Прежнее условие применяется и явно показано; удаляется только явным действием; сохранённые предпочтения не затёрты |
| F02 | Открыть новую панель гостем и клиентом | Все 11 опций доступны, состав экспертов соответствует роли |
| F03 | Выбрать два направления с разными и общими экспертами | Объединение совпадений, каждый профиль один раз |
| F04 | Добавить тему к двум направлениям | Пересечение группы направлений с темой |
| F05 | Применить поиск, снять условие со страницы 2, обновить, Back/Forward; вернуть исчезнувшую страницу | Изменение условий ведёт на страницу 1; номер сверх диапазона приведён к последнему; URL, выбор и результат согласованы |
| F06 | Задержать и ошибочно завершить поиск; поменять выбор; повторить | Различимые состояния, ввод сохранён, старый ответ не замещает новый |
| F07 | Набор содержит online/busy/offline и закрытый профиль | Гость видит только online; клиент три статуса; закрытый не виден никому без права |
| F08 | Подменить параметры и открыть прямую ссылку | Без утечки и обхода доступа; понятное восстановление |
| F09 | Сохранить, обновить, вернуть настройку; повторить без прав | Только разрешённое сохранение, журнал и возврат; вторая настройка неизменна |
| F10 | Пройти указанную матрицу размеров, локалей и ввода | Панель читаема, доступна, без наложений и влияния на оболочку |
| F11 | Добавить обычных пользователей и скрытые анкеты; поиск/сброс/пагинация | Они не включены ни в карточки, ни в число результатов и страниц |
| F12 | Изменить черновик и закрыть всеми способами; затем Search/Reset | Отмена не применяет, Search применяет, Reset очищает; фокус возвращается |
| F14 | Сопоставить профиль, справочники и каждую опцию | Реальные совпадения, четыре отсутствовавших понятия не подменены, старые поля сохранены |
| S01 | Пройти все четыре сочетания настроек; два окна админки | Независимость, сохранение, обнаружение конфликта и сохранность v1 |

Все серверные критерии сейчас имеют статус «Не проверено»: этот комплект не внедряет функцию в приложение. Результат Игоря: ссылка на реализованные страницы и короткое описание сделанного и оставшихся ограничений; затем проверка по этой таблице.
