# Параметры общего прогона

`python qa-cases.py` выводит 128 сочетаний и `expected_reference` в формате JSON Lines. Ожидания сохранены из предыдущей матрицы и служат ориентиром; перед тестированием сверить их с действующей реализацией и правами сайта. `python qa-cases.py --roles` подготавливает 32 сочетания восьми ролевых сценариев с вариантами фильтра и карточек. Отсутствие действия в конкретном шаблоне обосновать отдельно: например, «+N» относится только к новой карточке.

Это только генератор случаев: он не вызывает сайт, не проверяет права и не выдаёт PASS. Использовать данные в одном общем параметризованном прогоне существующего тестового механизма для реальной проверяемой логики на изолированных данных, без 128 или 32 ручных переключений. Если нужный уровень не покрыт или тест не выполнялся, зафиксировать остаток и статус в общей приёмке.

Четыре сочетания двух признаков поиска для гостя, Free и Premium, экспертные статусы, недоступные поля и сквозные браузерные сценарии проверяются дополнительно: они не входят в эти 128 комбинаций. Два ТЗ используют один общий прогон и одно доказательство. Production-настройки не изменять.
