# Настройки каталога экспертов

Готовый экран со штатной оболочкой, локальными ресурсами и взаимодействиями: [admin.html](../../admin.html). В самом макете нет редакторских пометок или панели управления тестами.

- [catalog-settings.html](catalog-settings.html) — готовая разметка блока в том же виде, что на экране.
- [catalog-settings.css](catalog-settings.css) — стили внутри `.cl-catalog-admin`. Базовые классы формы и кнопок используют существующие стили админки.
- Фильтр: `1` «Горизонтальный фильтр», `2` «Вертикальный фильтр». Выдача анкет: `1` «Знакомства», `2` «Эзотерика». Сохранение одного выбора не меняет второй.

Связать разметку со штатным сохранением, правами и журналом по ТЗ. Демо-скрипт `admin.js` и замороженную оболочку `admin-shell/` не переносить на рабочий сайт. Тестовые состояния доступны при локальной проверке по параметру `scenario` (`error`, `conflict`, `readonly`); отдельного поля для них в интерфейсе нет.
