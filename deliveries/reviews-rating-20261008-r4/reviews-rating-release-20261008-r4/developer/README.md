# Отзывы #62 — r4

Актуальный вход: `index.html`. Обязательное дополнение для реализации: `ROLE-MODERATION-HANDOFF.md`; оно заменяет противоречащие ему положения r3/старых документов этого пакета.

В админке три страницы: Отзывы (модерация), Написать отзыв (супер-администратор), Настройки отзывов (супер-администратор). В настройках находятся общий режим модерации и ручной рейтинг/голоса. В обеих формах отправки есть анонимность и оценка без текста.

Запуск макетов: любой локальный статический HTTP-сервер над папкой developer или над родительской папкой. Общие синтетические данные сохраняются в localStorage между страницами одного origin. Query-примеры `reviews`, `ratingMode`, `moderation` изолированы в памяти страницы. `?role=moderator` / `?role=superadmin` и `?lang=ru` / `?lang=en` — только переключение демонстрации, НЕ авторизация.

`reviews-rating-model.js` — чистая модель рейтинга/валидации. `reviews-admin-workflow.js` — синтетические переходы, capabilities, публикация и закрытый аудит. Три административных страницы используют общий `reviews-admin-shell.js`. Клиентский интерфейс сохранён в существующем YouDate-макете.

Публичный список содержит только опубликованные тексты. Число голосов включает опубликованные оценки без текста. Pending/rejected/hidden/deleted не входят в автоматический расчёт. Ручной override не создаёт недостающие записи. Анонимность скрывает имя публично, но не от проверяющего. Источник административной записи сохраняется в закрытом аудите; фиктивной оплаченной консультации нет.

Backend, база данных, реальные RBAC-права, платёжный допуск и действующий сайт НЕ изменены и НЕ проверены. Перенос localStorage/Query role в production запрещён. Серверная приёмка перечислена в handoff. r3 сохранена отдельной неизменённой поставкой.

Пакет developer не содержит QA-снимков, node_modules или внутренних рабочих журналов. Контроль состава и SHA256: `manifest.json`; проверяемые результаты находятся в отдельном QA-пакете.
