## UI Источники

Клиентская оболочка, фото и логотип унаследованы из r2: публичный профиль Marcus Antoniu на Confideline. Admin shell унаследован из предоставленного Заказчиком `support-ticket-queue-final.html`, Bootstrap/AdminLTE и custom.css. Исходники саппорта не редактировались; источник не доказывает backend-готовность. Прежняя provenance остаётся в неизменяемой r2; QA r3 хэширует все поставляемые UI-файлы и ресурсы.

В CSS r2 были ссылки на отсутствующие флаги, фоновые изображения и неиспользуемые шрифты. В r3 CSS parser удалил только декларации с неразрешимыми локальными URL; действующие локальные шрифты, фото и логотип сохранены. Scoped CSS админки выводит текст YouDate. В admin CSS сохранён необязательный внешний Inter stylesheet с системным font fallback. Структурный аудит проверяет весь локальный CSS/HTML resource graph; доступность внешнего шрифта этим аудитом не доказывается. Текущий браузерный прогон не является offline-тестом.

Предложения PM не превращаются в решения посредством упаковки. Карточка #62 является source pointer; её содержимое не переизвлечено и не изменено.
