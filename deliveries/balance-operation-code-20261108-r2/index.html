Операции баланса — показывать код в одну строку

Проблема на стенде

В админке откройте Финансы → Транзакции и найдите операцию №274. В колонке «Код» буквы длинного значения идут вертикально, по одному символу на строку. Из-за этого вся строка операции занимает около 495 px вместо обычных 56 px при ширине окна 1280 px. Одну операцию приходится прокручивать почти на высоту экрана. Операции баланса

Рисунок 1. Текущее состояние на стенде, 8 ноября 2026 года. Под заголовком «Код» видны прочерк соседней строки и длинный код операции №274, разорванный по буквам. Снимок обрезан по границам колонки, чтобы скрыть соседние данные.

Что должно измениться

На этой странице код читается в одну строку. Если значение длинное, в ячейке видно начало и многоточие, а рядом остаётся штатная кнопка копирования. Полный код виден в подсказке и вставляется целиком после копирования. Короткий код виден целиком, пустое значение показано прочерком. Локальный пример целевого вида

Как проверить после исправления

  1. Откройте операцию №274 на стенде. Код занимает одну строку, кнопка копирования находится в той же ячейке, высота строки определяется обычным содержимым таблицы.
  2. Наведите на код, затем нажмите «Копировать код» и вставьте значение в текстовое поле. Подсказка и вставка показывают полный исходный код без многоточия.
  3. Сверьте короткий код, пустую ячейку и узкое окно. Короткий код виден целиком, пустой показан прочерком, по горизонтали прокручивается таблица. Соседние колонки и остальные финансовые таблицы сохраняют прежний вид.

Подключение

Подключите CSS правки колонки после действующих стилей таблицы на balance-transaction/index. Ширина колонки в локальной правке — 160 px. Перед подключением сверьте #finance-ledger-grid, .transactions-grid-view, .tx-col-code и .finance-copy-value с разметкой целевой сборки. Если подсказки ещё нет, добавьте существующему элементу <code> атрибут title с полным экранированным значением. Сохраните полное значение и штатный обработчик копирования. Для внедрения нужен отдельный CSS этой колонки. Оболочка, суммы, запросы, фильтры, порядок колонок и права остаются прежними.

Что уже проверено. В текущей админке подтверждён исходный дефект. Патч проверен в локальной копии r9 с синтетическими кодами на ширинах 390, 767, 1024, 1280, 1440 и 1920 px. Штатный обработчик демо получил полное значение, системный буфер не проверялся. Проверка после внедрения на стенде остаётся открытой.
