# Существующие сценарии R01–R10

Исторический проект плана 28.09 с последующими уточнениями идентичности. НЕ утверждённая матрица всех полномочий и НЕ результаты тестов. Приоритет у актуального ТЗ 15.10 и принятых решений, подтверждённых источником. Каждый ожидаемый результат связывается с действующим правилом перед runtime-проверкой.

Особенно: R03 про закрытые служебные заметки не запрещает агенту обычные рабочие чаты с сотрудниками. R07 про утверждение денежного запроса и запрет самоутверждения — историческая гипотеза, не принятая PSP-политика и не новое ограничение согласованных credits/выплат. R06/R08/R09 также не создают полномочий одним названием роли. R02 не даёт клиенту admin-shell или staff payouts. В этой поставке сценарии не выполнялись.

| ID | Контекст | Положительный пример исторического плана | Отрицательный пример исторического плана |
|---|---|---|---|
| R01 | Гость | Видит только опубликованный профиль E1 | Черновик E2, аккаунт, чат, тикет, вложение, платёж — отказ без данных |
| R02 | Клиент C1 | Видит свой баланс, заказ O1, диалог E1, клиентскую ленту T1; может ответить в разрешённом состоянии | Подмена ID на C2/T2/O2 и открытие internal/participant API — отказ; письмо/уведомление не содержит чужого текста |
| R03 | Эксперт E1 | Видит назначенный диалог и свой адресный вопрос, выполняет разрешённое действие сессии | Диалог E2, общий Internal T1, возврат, чужая анкета/сессия — отказ |
| R04 | Эксперт H1 во внутренней роли агента A | Работает с назначенными диалогами E1a/E1b; переключение сохраняет правильный профиль, адресата и историю; дополнительные админ-функции только по праву | Профиль/диалог E2 человека H2 — отказ; подмена profile ID и отправка из старой вкладки после переключения не смешивают авторство; `*-all` не обходят scope |
| R05 | Support S1 | Работает в назначенном T1, открывает client-канал и адресный вопрос, создаёт запрос действия | T2 вне назначения/полномочия, прямой refund POST, оригинал блокировки, публикация чужой заметки клиенту — отказ |
| R06 | Старший Support S3 | Видит эскалированный T1 и выполняет утверждённые старшие действия | Не получает право денежного исполнения или чтения всего сайта автоматически; повторную жалобу не рассматривает исходный решавший сотрудник |
| R07 | Денежный исполнитель F | На тестовом утверждённом запросе выполняет одну операцию, видит результат в журнале | Неутверждённый/чужой запрос и повтор той же операции — отказ или идемпотентный неизменный результат; сам не утверждает собственный запрос |
| R08 | Super Admin SA | По заданной причине открывает один заблокированный оригинал; доступ записан | Просмотр без причины/в обход контрольного action не проходит; аудит содержит актёра, объект, время и основание, но не размножает исходный текст |
| R09 | Редактор/публикатор анкеты | Редактирует или публикует только по отдельно выданному праву | Эксперт сам не публикует неподтверждённые утверждения; чужая роль не меняет статус прямым POST |
| R10 | Общий регресс | После смены роли/назначения новые права применяются согласно контракту | Старые вкладки, ссылки, attachment URL, WebSocket и кэш не сохраняют доступ после отзыва прав; журнал фиксирует изменение роли |
