# Codex + Dots Vally: решение по #49, 15.10.2026

## Согласованное решение

Сейчас #49 можно передать Игорю на техническое уточнение существующей системы прав. Новый RBAC, повторный аудит всех экранов и пересогласование принятых ролей не нужны. От Алексея пока не требуется новых решений.

Игорь возвращает один минимальный результат:

1. Точный commit, фактически развёрнутое окружение, состояние миграций и применённую конфигурацию прав. Одна ветка не идентифицирует сборку и текущие настройки.
2. Одну карту: действие → permission → пользователь/профиль → точная связь «свои/назначенные/все» → серверный обработчик/проверка → доказательство → статус. Для «своих» указать конкретно: аккаунт, профиль, назначенный оператор либо автор обращения. Показать существующее сложение прав нескольких профилей одного человека, не вводя новую политику.
3. Раздельные статусы: подтверждено на сборке; найдено в коде, исполнение не проверено; требуется настройка; требуется исправление; требуется продуктовое решение.
4. Короткий список доказанных расхождений с принятыми правилами и план адресных разрешённых/запрещённых случаев: прямые чужие ID, вложения, realtime, отзыв назначения/доступа, включая уже открытый канал. Списки, поиск и экспорт включать только при наличии такого пути к этим данным. Исполнение live-проверок остаётся на паузе.
5. Только действительно неурегулированные продуктовые исключения с текущим поведением, отсутствующим правилом и последствиями решения. Сначала найти существующее правило и источник его принятия.

Алексею возвращаются только исключения без ранее принятого правила: чтение чужих консультаций без назначения; цепочка запроса, утверждения и исполнения PSP refund; намеренное делегирование выдачи прав/глобальных настроек. Это кандидаты для уточнения после ответа Игоря, не три обязательных повторных согласования. Предлагаемые безопасные ограничения не считаются принятыми автоматически.

Ранее согласованные финансовые роли и owner-bound личные финансы сохраняются. Корректировки credits, выплаты сотрудникам и PSP-возврат клиентского платежа различаются. Агент/эксперт остаётся одним человеком с несколькими профилями. Клиент в админку не входит. STOP #23, пауза live-QA #25 и hold #73 сохранены.

Разногласий по этому следующему шагу не осталось. Dots не читала новую сборку или первичный документ Игоря 07.10 в этой сверке; финансовые решения она учитывает по переданным Codex данным. Codex сверил документ локально ранее. Совместное решение не является независимой проверкой реализации этих прав и не повышает приёмку безопасности.


Это исходное согласование следующего шага; предметная сверка текущего комплекта отдельно описана в [REVIEW.md](../REVIEW.md). Частная переписка и служебные записи браузера не входят в публичный архив.
