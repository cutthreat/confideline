# Доказательства для этой редакции

Release id: `reviews-rating-20261001-r2`.

Этот developer-пакет содержит требования и макеты, не QA PNG или runtime tools. Полные результаты, снимки и тестовый harness находятся в отдельном архиве `reviews-rating-qa-20261001-r2.zip`; его точка входа после распаковки - `qa/index.html`.

QA-пакет привязан к SHA256 developer `manifest.json`. Одного совпадения даты недостаточно: при изменении исходников нужен новый manifest и новый тест. `qa/manifest.json` и `QA-RESULTS.json` содержат release id и developer-manifest hash. Для проверки целостности архива использовать передаваемый `RELEASE.json` из полного локального release-индекса.

Проверено локально: пять ширин 1440/1024/768/390/360, rated/unrated/ineligible, первый отзыв, hide/restore/delete, форма, безопасный вывод текста, фильтры, причины, аудит, фактическая геометрия sidebar, загрузка изображений/шрифтов и работа без сети. В QA-индексе отдельно приведены извлечённые архивы, ссылки, хэши и отрицательные проверки. Фактические результаты и число PASS читать в QA-RESULTS, не выводить из этого описания требований.

Не подтверждено: серверная RBAC, DB/уникальность/гонки, интеграция двух экранов, реальные события/доставка, deployment, независимая product acceptance и приёмка Заказчиком. Серверный QA имеет статус NOT_RUN до появления сборки и необходимых ролей.

В evidence нет старых `reviews-admin-<width>.png` встроенной демонстрации или снимков прежней страницы пакета. PNG сгруппированы как реальные текущие UI-состояния, а не как ресурсы для внедрения. Все локальные результаты относятся к exact source snapshot, не к действующему сайту.
