Редакция: `reviews-rating-20261001-r2`. Статус: готово для просмотра/реализации, не backend acceptance.

Открыть `index.html`. Сервер, установка зависимостей и QA-архив для просмотра макетов не нужны. Ссылки и ресурсы основного пакета относительные. Если открывается только Markdown-текст, использовать HTML-индекс для перехода к макетам.

## Состав

- `HANDOFF.md` - результат, решения, backend binding, сценарии, ошибки, ожидаемый QA и открытые вопросы.
- `CONTRACT.md` - требования первой версии; правило без оценок обновлено 01.10.
- Два HTML-макета, их CSS/JS и нужные assets - текущая анкета и отдельная админка.
- `SOURCE-PROVENANCE.md` - происхождение, ограничения и связь с каноническими источниками.
- `EVIDENCE.md` - какой QA-пакет относится к этой редакции, как отличить доказательства от требований.
- `manifest.json` - SHA256 всех файлов этого developer-снимка, кроме самого manifest.

Демонстрационные отзывы/консультации не являются реальными данными. Состояния страниц независимы и не сохраняются после reload. Встроенная демонстрация модерации в клиенте - вспомогательный тест; для реализации admin использовать отдельный HTML. Прочие разделы sidebar не подключены к действующей админке.

**Обязательное принятое правило:** при нуле опубликованных оценок строки рейтинга под именем нет, без текста, звёзд и отступа. Первый отзыв показывает stars/average/count. В разделе отзывов остаются пояснение и допустимая кнопка.

QA PNG, тестовые runtime tools, внутренние журналы/память, старые экраны, реализация backend/RBAC/DB, реальные платежи, уведомления, deployment и человеческая приёмка. Необходимые изображения/шрифты в assets - ресурсы интерфейса, не QA-доказательства.
