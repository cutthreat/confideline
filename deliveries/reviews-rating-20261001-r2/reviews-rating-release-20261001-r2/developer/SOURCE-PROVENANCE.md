Исходники саппорта не редактировались; источник не доказывает backend-готовность. SHA шаблонов сохранены в source-provenance QA.

В source admin CSS указаны отсутствующие в полученном шаблоне файлы фонового логотипа. Scoped CSS макета выводит существующий текст YouDate вместо запроса отсутствующих изображений. Остальные skin/layout правила не заменяются. Google/Inter stylesheet может быть заблокирован offline; текущие экраны должны оставаться читаемыми на fallback fonts. Активные локальные assets проверяются отдельно.
