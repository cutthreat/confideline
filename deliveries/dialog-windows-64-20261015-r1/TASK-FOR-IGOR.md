## Что проверить

1. Указать проверяемый коммит или сборку.
2. В существующем реестре отметить: уже работает / требуется подключение / требуется исправление. Дополнить только известные пропуски, включая динамические и административные окна; не составлять перечень заново.
3. Для затронутых окон подтвердить страницу, условие открытия, роль, серверный источник состояния, файл/обработчик и результат основных кнопок.

## Что исправить

Подтвердить на текущей сборке и устранить ранее обнаруженные дефекты:

- При открытии фокус попадает в окно, не уходит на фон и после закрытия возвращается к инициатору. Фон недоступен с клавиатуры; исключено случайное открытие второго окна поверх первого.
- У окна выбора языка есть доступное название. Escape, крестик и закрытие работают предсказуемо. Ранее Escape работал внутри окна, но не при оставшемся на фоне фокусе; не считать всё закрытие неработающим.
- В Contact Filter новая форма не наследует прокрутку предыдущей; ошибка сохранения не сбрасывает фокус на страницу; Escape закрывает незавершённый календарь.

Основание: наблюдения окон языка/страны/города от 07.10, независимое подтверждение части проблем от 13.10; три наблюдения Contact Filter от 12.10. Это список известных дефектов для адресной сверки, не новый прогон 15.10 и не утверждение, что они ещё присутствуют в последней сборке.

Сохранить существующий дизайн каждой поверхности. Проверять повторно исправленные сценарии и затронутое общее поведение, а не все ранее рабочие окна. Не выполнять реальные оплаты и не расширять эту задачу на отдельные карточки баланса, Support, отзывов и прав.

## В каком виде вернуть результат

1. Обновлённый существующий реестр или таблицу дополнений: `окно → страница/условие → роль → статус → файл/обработчик → результат проверки`.
2. Ссылку на коммит/PR и проверяемую сборку, короткий список изменённых файлов.
3. Короткую запись экрана либо снимки с описанием шагов для исправлений: клавиатура, закрытие и возврат фокуса; ошибка сохранения; узкий экран. Для фокуса нужен наблюдаемый сценарий, не только скриншот.
4. Нерешённые вопросы и ограничения отдельно. Не обозначать backend готовым только по HTML-примеру.

## Границы комплекта

Существующий статический объём: 88 исходных HTML, 54 экземпляра окон, 43 предварительные группы компонентов, 39 страниц с примерами и 702 файла примеров с зависимостями. Это не полный перечень самостоятельных бизнес-окон действующего сайта.

Макеты и их CSS/JS не перерисованы и не исправлены этой упаковкой. Реестр отражает исходную редакцию 08.10; подготовка публичного комплекта 15.10 не делает наблюдения новыми. В публичной копии реестра абсолютные пути заменены переносимыми обозначениями источников, сохранены ID, исходные хеши и статусы. Источники с пометкой «на паузе» остаются недоступными из навигатора. В старых примерах могут встречаться наследованные подписи; это не новая продуктовая рекомендация.

HTML открываются без сборки. Локальная навигация через iframe зависит от правил браузера; публичный навигатор доступен по HTTPS. Отдельные примеры можно открыть через «Открыть отдельно». Это fixtures, без подтверждённого backend и без приёмки финансовых/сессионных операций.
