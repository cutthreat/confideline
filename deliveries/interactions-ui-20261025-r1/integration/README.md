# Только рабочий блок «Взаимодействия»

Эта папка — единственная поставка для адаптации в действующем сайте. Полные HTML-страницы, шапка, логотип, меню, общие CSS/JS и демонстрационные данные в неё не входят.

1. Сохранить штатные AssetBundle и оболочку сайта. Не переносить ресурсы из `preview/content`, `preview/external` и `preview/demo`.
2. Выбрать один ролевой `*.partial.html` и встроить его в существующую рабочую область `#interactionReport`, сохранив внешний контейнер действующего контроллера. Все новые изменения находятся во вложенном `#confideline-interactions`; одинаковые ID трёх шаблонов не должны появляться одновременно.
3. Подставить серверный scope (`partnerId`, `expertId`, роль, доступные профили и права) и `report.nowIso` вместо обозначений `{{ ... }}`. Это не готовый PHP-шаблон и не источник прав доступа.
4. Подключить `interactions.css` после штатных стилей. Каждый селектор этого файла ограничен корнем рабочего блока. Здесь нет `body`/`html`, глобального reset, `@font-face`, стилей шапки или бокового меню.
5. Визуальные адаптеры подключаются после существующего контроллера: `interactions-layout.js`, `interactions-popovers.js`, `interactions-compact.js`, `interactions-date.js`. Инициализация относится только к корню блока. Согласовать существующие ID/события с шаблоном; это адаптеры вёрстки, не замена работающего контроллера, запросов, расчётов или RBAC.
6. Для календаря использовать зарегистрированные JS-библиотеки сайта (jQuery, Moment и DateRangePicker), без повторного подключения jQuery и глобального CSS плагина: правила календаря уже ограничены корнем в `interactions.css`. Для иконок — существующий Lucide. Получение данных, ошибки, загрузка и серверное применение фильтров остаются у действующего контроллера.

## Приёмка интеграции

| Экран / действие | Ожидаемый результат |
|---|---|
| Открыть любую роль | Доступные данные и показатели определяет сервер; оболочка и штатная навигация сохраняются |
| Выбрать вторую дату | Диапазон сразу появляется в фильтре, календарь закрывается; отчёт не обновляется |
| Нажать общую «Применить» | Один штатный запрос с выбранными фильтрами; данные и ошибки обрабатывает существующий контроллер |
| Выбрать пиктограммы / столбцы | Меняется представление; текущие фильтры и расчётные итоги сохраняются |
| Открыть меню и графики | Выборы и всплывающие панели остаются в области функционала, не перекрывают штатную шапку |
| Сравнить страницу до/после подключения | Шапка, логотип, поиск и меню сохраняют CSS, размеры и поведение боевого сайта |

Макеты используют демонстрационный renderer отдельно от этой папки. Копировать его на сайт нельзя. Локальная проверка превью не заменяет приёмку подключения к Yii/backend. Прежние общие пакеты v2–v5 содержат демонстрационную оболочку и не являются текущей поставкой для переноса.
