# CSS: неизменяемая основа и локальный функционал

Утверждённая основа этой поставки — агент v8.1. Новых правил для global_custom, html/body, main-header, logo, navbar, sidebar и footer нет. Все production additions ограничены #confideline-interactions. В preview неизменённые site/vendor CSS нужны только для точного просмотра; их наличие не означает необходимость копирования/замены на сайте.

На боевом сайте возможны отличия от архивных макетов заказчика. Не исправлять их глобальной темой из этого ZIP. Сначала сверить фактически зарегистрированные assets и наследование внутри целевого блока; коллизию устранять локальным адаптером с тем же root. Изменение внешней оболочки в задачу не входит, даже если отличается global_custom из старого балансового архива.

Файлы preview/assets/content и external — замороженные исходные байты для воспроизводимости. Их hashes в SOURCE.json. integration/interactions.css совпадает с активным interactions-ui-v8.css принятого макета. JS также не переписан. В переносной версии изменены только пути ресурсов, демонстрационная навигация и обезличена учётная запись в шапке; карточки профилей используют локальные копии предоставленных публичных фото. Реальные данные счёта/учётной записи не передаются.

Проверять до/после подключения root: шрифт, line-height, border, padding, computed style общей оболочки. Рамку контрола, wrapper и центры содержимого измерять отдельно. СовпадениеCSS-высоты не заменяет скриншот. ОтчётQA фиксирует авторскую проверку, без заявления независимой экспертизы или полного соответствия WCAG.

Для повторного PJAX-монтирования существующий controller должен уничтожить свои слушатели/observers и заново инициализировать новый root. Идущие в комплекте адаптеры рассчитаны на одну обычную загрузку; lifecycle нужно связать с действующим controller и проверить по INT-14, а не повторно исполнять script-теги после каждого PJAX.
