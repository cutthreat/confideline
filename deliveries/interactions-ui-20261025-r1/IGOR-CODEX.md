# Игорю: взаимодействия · утверждённый UI v8.1 · комплект r1

Основа — принятый Алексеем25.10.2026 макет агента partner.html?revision=ui-v8.1#charts. Макеты админа и эксперта используют те же файлы и общие компоненты. Это полный комплект по странице взаимодействий, без финансов и цензуры.

## Порядок работы

1. Открыть index.html через HTTP или опубликованную страницу. Просмотреть три роли и три вкладки. Папка preview — демонстрация, её оболочку/renderer/фикстуры на сайт не переносить.
2. integration/README.md описывает восемь файлов для адаптации: три ролевых partial и пять общих CSS/JS. Использовать только один partial на страницу. Сохранить существующий #interactionReport, вложить #confideline-interactions.
3. Сохранить действующие AssetBundle, Yii/controller, AJAX, источники расчётов и серверные права. Подставить server scope и nowIso. Метки data-audience/partnerId/expertId сами по себе не защищают данные.
4. Подключить interactions.css после существующих CSS; затем interactions-layout.js, interactions-popovers.js, interactions-compact.js, interactions-date.js после действующего controller. Названия нормализованы; содержимое соответствует активным *-ui-v8 файлам v8.1, старые одноимённые файлы из preview не брать.
5. Календарь использует уже подключённые jQuery/Moment/DateRangePicker и принятую локальную адаптацию. Не ставить второй календарь/шрифт/Bootstrap; не переносить стили из preview/assets.
6. Пройти ACCEPTANCE.xlsx. Отдельно подтвердить реальные запросы, серверный отказ чужому scope, ошибки, отмену/повторную загрузку и teardown при PJAX. Это предел данной поставки: preview не подтверждает backend/RBAC.

## Зафиксированные решения

- Три вкладки: Сводка, Взаимодействия, Графики.
- Иконки в заголовках таблицы, пояснение hover/focus, переключение подписей. Фильтрация не меняется от режима заголовков/столбцов.
- В календаре нет второго подтверждения: даты сразу подставляются; результат обновляет общая Применить.
- Кнопки и меню едины для трёх ролей. Показатели12px/18px, спокойное выделение, независимые иконки/счётчики без унаследованных рамок/отступов.
- Меню прикреплено к своему рабочему блоку и не заходит под системную шапку; размеры ограничены доступным экраном.
- В кнопке Эксперты снят унаследованный margin-bottom у span; не компенсировать смещение transform/top/отрицательным margin.
- Админ видит13 метрик при наличии глобального разрешения; агент и эксперт11. У эксперта нет выбора чужих профилей. Не выравнивать роли добавлением недоступных функций.

## Данные и интеграционный контракт

Действующая реализация остаётся источником истины. Имена на страницах взяты из публичных профилей; все события, назначения, показатели и связи демонстрационные. Снимок now=01.10.2026, период07–15.09.2026, Europe/Minsk. Это не аудит активности этих людей.

Запрос отчёта должен передавать только разрешённый scope, период, направление, запрос клиента и minActions; формат/endpoint оставить действующим. Сервер независимо определяет доступные профили/метрики, а не доверяет data-атрибутам. Таблица, сводка и график получают одну подтверждённую выборку. Сортировка/вид/столбцы — представление; не терять фильтры.

Новые Chat/Ping — факты жизненного цикла (chatCreatedAt/pingCreatedAt), не вывод из сообщений или просмотров. Парные суммы/консультации учитываются один раз. Денежные значения — credits с точной арифметикой; null/отсутствие источника не0. LTV пары и платформы не смешивать; платформенные показатели только глобальному доступу. Исторические правила и источники расчётов не переписывать ради нового UI.

preview/assets/demo/assets/partner-interactions-analytics.js и соседние modules сохранены как иллюстрация согласованного поведения на фиксированных данных. Это не новый production controller и не разрешение заменить им серверные расчёты. Для интеграции достаточно mapping действующего controller на partial/DOM и события адаптеров.

По окончании: build/commit → роль → исходные данные → действие → ожидаемое → факт → доказательство. Production rollout отдельно от этой Git-передачи; прежние41 live-проверки этой поставкой не закрываются.
