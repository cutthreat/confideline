## Согласованные правки владельца, включённые в R2

Внедряет Игорь. Отдельные дополнения передавать не нужно. [Полные правила и критерии](sources/OWNER-DECISIONS-20261028.md).

- **CHAT-RATING-01** — Рейтинг (звёзды, средняя оценка, число голосов/отзывов) только в профиле эксперта; во всём чате, включая список и шапку, отсутствует. Избранное и действие оценки завершённого сеанса сохраняются; пустого отступа нет.
- **CHAT-PRESENCE-01** — Единый актуальный статус в списке и шапке: зелёный В сети / Online, жёлтый Занят / Busy, серый Не в сети / Offline. Существующие стили, текстовая расшифровка и доступное имя сохранены.
- **CHAT-PAID-AVAIL-01** — При занятости/оффлайне кнопки нового запроса/начала нет, в том числе в Tab-порядке. Сервер проверяет доступность до начала/первого списания: при устаревшем статусе нет нового сеанса/дебета. Статус и кнопка обновляются вместе; управление текущим сеансом сохраняется.

По рейтингу сохранён FAIL по снимку владельца. Два новых требования имеют NOT_RUN: внедрение и проверка ещё ожидаются. Это не отменяет прямое поручение их реализовать.

## C. Что мешает закрытию

- **CHAT-TRIAL-01**. У клиента #189 сервер показывает No trial minutes remain. Не пополнялись trial и не менялись настройки/права. Ответственный за проверку: **Игорь / Codex по указанному следующему шагу**. Далее: Игорь: подготовить существующий тестовый аккаунт с остатком trial; Codex: пройти две стороны.
- **CHAT-LOW-BALANCE-01**. Клиент #189 имеет положительный баланс. Реальная покупка, обнуление кошелька и изменение прав ради fixture не выполнялись. Ответственный за проверку: **Игорь / Codex по указанному следующему шагу**. Далее: Игорь: дать разрешённый low-balance fixture и явно видимый Stripe test; Codex: проверить отказ/возврат.
- **CHAT-OFFER-EXPIRY-01**. Не изменялись часы, тарифы, TTL или серверные события. Новая цена/истечение не воспроизведены. Ответственный за проверку: **Игорь / Codex по указанному следующему шагу**. Далее: Игорь: дать управляемые short-TTL/changed-offer fixtures; Codex: проверить обе стороны.
- **CHAT-RACE-01**. UI-retry одного сообщения проверен; гонки финансовых команд и server-side replay не выполнялись и этим не доказаны. Ответственный за проверку: **Игорь / Codex по указанному следующему шагу**. Далее: Игорь: предоставить изолированный серверный сценарий по регламенту; Codex: сопоставить ledger.
- **CHAT-ACL-01**. Положительные роли и приватность support note проверены. Отрицательный контроль другим клиентом и прямой URL чужой тестовой записи не выполнен. Ответственный за проверку: **Игорь / Codex по указанному следующему шагу**. Далее: Игорь: дать второй ограниченный аккаунт и его разрешённую контрольную запись; Codex: проверить 403/404.
- **CHAT-DEVICE-01**. Выполнены CSS viewport 360/480/768/992/1280 при scale=1; физические телефоны не подключены. Ответственный за проверку: **Игорь / Codex по указанному следующему шагу**. Далее: Codex: выполнить на доступных реальных iPhone/Android; CSS-размеры не повышать до device PASS.

Далее: Подготовить отдельный disposable-диалог и применимый допуск финального удаления; затем проверить readback.
