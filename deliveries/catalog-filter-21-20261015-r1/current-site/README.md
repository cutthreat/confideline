Один компонент в двух оболочках. Искусственные профили общие, реальные данные подключает backend. В публичной auth-копии данные аккаунта заменены демонстрационными без изменения структуры шапки. Соседние действия оболочки отключены.

Проверка модели и адаптера: `node --test filter-model.test.cjs filter-data.test.cjs`. DOM-suite и локальные привязки машины не входят в публичный пакет.
