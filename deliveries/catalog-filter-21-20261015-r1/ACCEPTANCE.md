## Фикстуры И Доказательства

Для каждой из 11 опций нужен профиль с точной связью либо явно описанное отсутствие соответствующих профилей без фиктивного результата. Нужны случаи двух значений одной группы, пересечения групп, совпадения одного профиля по нескольким связям, пропуска необязательного поля, no-match, busy, offline и недопуска.

Разные профили одного человека не объединять автоматически; исключать только повтор одного и того же профиля из-за join. Для каждого сценария фиксировать вход, роль, точную сборку, ожидаемые и фактические ID/total/page, доказательство и результат. Реальные пользователи и деньги для этого не требуются.
