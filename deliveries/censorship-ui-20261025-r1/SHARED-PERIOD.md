# Период журнала

Эталон: существующий фильтр «Дата заявки» страницы /ru/admin/payout/index. Использовать его finance-date-filter + form-control + calendar/clear и штатный общий инициализатор DateRangePicker.

1. Сохранить текущие AssetBundle и регистрацию jQuery/Moment/DateRangePicker. Существующий CSS не переписывать. Пример разметки — snippets/shared-period.html; name/id и параметры формы согласовать с текущим Yii view.
2. Оставить hidden date_from/date_to для существующего contactFilterForm. На apply/clear общего компонента обновлять эти поля и запускать штатное событие фильтрации. Не вводить второй независимый apply-процесс и не менять правила запроса.
3. Убрать прежнюю input-group/drp-container вокруг вставленного компонента: float поля обнулял высоту calendar/clear. Использовать штатную обёртку целиком, с уникальным aria-controls.
4. Область существующих finance-date-filter-правил задаётся обёрткой finance-page вокруг таблицы; проверить наследование и регистрацию финансового адаптера только там, где нужен компонент. Не добавлять новые широкие правила для всех input/table/body.
5. В таблице данные даты12px; у существующего поля фильтра11px/30px. Параметры календаря, локаль и очистка — общая реализация. Если общий инициализатор пока жёстко связан с финансовой формой, выделить существующую логику в общий компонент с параметрами, без локальной CSS-копии.

В preview общий компонент подключён к фиксированным данным локальным period-preview.js. Это демонстрация контракта, не production-контроллер; этот JS на сайт не переносить.
