# Цензура — комплект правок для Игоря · 25.10.2026

Изменить только представление категорий и период на двух существующих страницах: журнал срабатываний и правила цензуры. Утверждённые решения Алексея из текущего обсуждения; основа — проверенные макеты v9.

## Что сделать

1. Журнал: четыре отдельные серые пиктограммы (почта, ссылка, телефон, сообщения), только для реально найденных категорий. На desktop hover и keyboard focus показывают конкретное название. Общей панели по клику/Enter нет.
2. Touch/coarse pointer: нажатие показывает/закрывает подпись конкретного значка. Видимый квадрат остаётся26×26; цель44×44. Это CSS-поведение, не доказательство физического телефона.
3. Правила: пиктограмма + текст; обычную и замаскированную почту различать модификатором конверта. Вариант рисунка — метаданные правила, не новый category enum и не ID2.
4. Период журнала: использовать существующий компонент выплат целиком. Сохранить имена date_from/date_to, применение фильтров и поведение формы. Отдельного нового календарного CSS нет.
5. Не менять основной шрифт таблицы/общую оболочку. Дата данных — основной12px, поле периода — штатные11px/30px. При несовпадении наследования исправить локальную разметку, не общий CSS.

## Подключение

- Сначала прочитать CSS-INTEGRATION.md и SHARED-PERIOD.md. Файлы integration относятся только к presentation. Новые PHP/API/миграции/права и детекторы этот комплект не добавляет.
- Корень журнала: data-contact-filter-page="incidents" и admin-icon-badges. Корень правил: data-contact-filter-page="rules" и admin-icon-badges. Уникальный root каждой страницы; оба шаблона одновременно в один DOM не вставлять.
- common-icon-badge.css, categories.css, rule-category-icons.css — только свои корни. Если общий transaction-type уже подключён корректно, повторно не объявлять его; использовать существующий.
- Иконки — существующий FontAwesome4.7; подсказки — уже зарегистрированный jQuery/Bootstrap tooltip. Не подключать второй jQuery, Bootstrap, шрифты, AdminLTE или global_custom.
- category-icons.js — совместимый presentation-адаптер для исходных текстовых меток; предпочтительно выдавать такую разметку сразу renderer-ом. rule-category-icons.js принимает data-category-variant / presentation_variant. Не менять шаблоны обнаружения ради рисунка.
- JS грузится один раз вне заменяемого PJAX-блока. После PJAX создать инициализацию для нового root; прежние observers/handlers не накапливать. Сверить root/события с действующим контроллером, preview-адаптеры на сайт не копировать.
