# Списки клиентов и экспертов

Редакция 7 от 10.11.2026. Начни с [ТЗ Игорю](../TZ.html). Разделы 1–4 задают результат для человека. Техническое приложение уточняет источники и правила внедрения. [Макет клиентов](../preview/clients.html), [макет экспертов](../preview/experts.html) и [таблица приёмки](../acceptance.xlsx) относятся к той же редакции.

1. Клиенты. Сверь источник каждого столбца с таблицей раздела 1.
2. Эксперты. Используй поля анкеты №17, №19, №20 и №21, как описано в разделе 2. Сверь источники рейтинга, связи с агентом и городов.
3. Действия. Сохрани штатные формы и разрешения. Проверь создание, назначение, отмену и ошибки.
4. Состав и права. Сверь отбор по типу анкеты и серверный доступ к конкретной записи.
5. Списки и ширина. Выполни проверки фильтров, переходов и вёрстки из раздела 4.

Работай по инструкциям репозитория продукта. Используй штатный CSS админки. Дополнительные правила подключай отдельным файлом на целевых страницах и ограничивай контейнером списка или формы. Демонстрационный JavaScript и вымышленные записи служат предпросмотру. После реализации верни результаты проверок 1–5 с доказательствами. При расхождении материалов сначала уточни основное ТЗ.
