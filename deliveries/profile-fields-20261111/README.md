# Поля профиля клиентов и экспертов

Основной документ для Игоря: [ТЗ в Google Docs](https://docs.google.com/document/d/1djDoc_cJOH4pi3VNJ-TkbwvQy83xdaYEQQlrpWEk46g/edit). В документе приведены снимки текущей страницы и согласованного варианта, сценарии и приёмка. Актуальные решения фиксируются в Google Docs.

Материалы комплекта:

- [Интерактивный макет страницы](preview/index.html). Настройки и данные примера сохраняются только в браузере.
- [Предпросмотр анкеты, формы и поиска](preview/preview.html). Открывать после настройки в макете: для обоих экранов используется локальное хранилище одного браузера.
- [Инструкция для Codex](CODEX.md).
- [Критерии приёмки](ACCEPTANCE.md).
- [Снимок действующей страницы](images/site-current.png) и [пример целевого состояния](images/mock-difference.png).
- [Копия ТЗ в DOCX](TZ.docx), экспорт 11 ноября 2026; при обновлениях сверять с Google Docs.

Макет описывает планируемое поведение. Он не подтверждает, что серверная реализация уже существует. Архив является дополнительным способом передачи, каждый файл доступен отдельно.
