# Приёмка: поля профиля

Основные условия и сценарии — [раздел 7 ТЗ](https://docs.google.com/document/d/1djDoc_cJOH4pi3VNJ-TkbwvQy83xdaYEQQlrpWEk46g/edit). Все пункты ниже относятся к будущей реализации; сейчас они не проверены на сервере.

1. Общее поле: независимо переключить каждый из четырёх флагов для клиента и эксперта, перезагрузить страницу и проверить сохранение выбранного типа.
2. «Только различия»: показать поля одного типа и общее поле с разным флагом одной из четырёх колонок; скрыть общее поле с одинаковыми флагами этих колонок. Форма и обязательность в сравнение не входят. При выборе одного типа фильтр снимается; проверить сброс и сортировку.
3. Встроенные пол, статус, «Я ищу» и обе границы возраста: отдельные настройки типов, форма и просмотр; после выключения и включения исходный ответ сохранён. В поиске «Я ищу» проверяет пол искомой анкеты, а возраст — дату рождения; не путать их с предпочтениями владельца анкеты.
4. Обычная и премиум-аудитория: для показа и поиска отдельно проверить четыре сочетания общего и премиум-флагов. Оба выключены — недоступно всем; только общий — доступно всем; только премиум или оба — доступно только премиум. Проверить анкету, фильтр, фактический поиск, API и выдачу из прогретого кэша с учётом прав.
5. Дополнительное поле: штатное создание и редактирование, подтверждение удаления; встроенное поле удалить нельзя.
6. Предпросмотр: тип анкеты, аудитория и три контекста соответствуют настройкам; возврат сохраняет состояние списка; примеры не изменяют анкеты.
7. Миграция и откат на копии: значения, ID, варианты, переводы и настройки не теряются; прямой запрос не записывает недоступное поле; ошибка не выдаётся за сохранение. Проверить потерянный ответ, частичный отказ индекса и конфликт одновременных правок.
8. Оболочка и существующие стили сохранены; новые правила ограничены контейнером. Десктоп соответствует макету, внутренней вертикальной прокрутки таблицы нет.
