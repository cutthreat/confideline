# Доказательства для этой редакции

Release id: `reviews-rating-20261008-r3`. Старые результаты r2 не используются как доказательство r3.

Этот developer-пакет содержит требования и макеты, не QA-снимки или runtime tools. Полные результаты, JPEG и чистые тесты находятся в отдельном архиве `reviews-rating-qa-20261008-r3.zip`; его точка входа после распаковки - `qa/index.html`.

QA-пакет привязан к SHA256 developer `manifest.json`. Одного совпадения даты недостаточно: при изменении исходников нужен новый manifest и новый тест. `qa/manifest.json` и `QA-RESULTS.json` содержат release id и developer-manifest hash. Для проверки целостности архива использовать передаваемый `RELEASE.json` из полного локального release-индекса.

Объём QA r3: пять ширин 1440/1024/768/390/360, manual/auto/zero, отзыв от выбранного автора, его hide/restore/delete, изоляция экспертов, отмена и фокус, безопасный вывод HTML, обязательные поля, фильтры и журнал. Клиентские rated/unrated/ineligible/first-review проверяются отдельно. Чистая модель имеет 32 unit-теста. Полный CSS/HTML dependency graph проверяется структурно, без маскирования 404 из r2; список механической очистки сохранён в `css-pruning.json`. Фактический статус, число проверок, снимки, хэши и границы читать в QA-RESULTS/native-runtime и RELEASE.json; описание сценариев само по себе не является PASS.

Не подтверждено: серверная RBAC, DB/уникальность/гонки, интеграция двух экранов, реальные события/доставка, deployment, независимая product acceptance и приёмка Заказчиком. Серверный QA имеет статус NOT_RUN до появления сборки и необходимых ролей.

В evidence нет старых снимков встроенной админки r2. JPEG показывают текущие состояния r3, не ресурсы для внедрения. Все результаты относятся к exact source snapshot макетов, не к действующему сайту.
