## Решения и открытые вопросы

**Принято Заказчиком:** немедленная публикация после серверной валидации с последующей модерацией; сохранить оригинальные блоки и сетку анкеты; отзывы внутри центрального блока; состояние без оценок без пустых звёзд/числового нуля; отдельная админка на существующей оболочке саппорта. Скрытие, восстановление и удаление требуют причины и аудита; учитываются только опубликованные отзывы.

**Предложено, не выдавать за согласованное:** запрет редактирования отправленного отзыва в v1; отсутствие автоматического удаления при возврате; soft-delete с сохранением аудита. До реализации уточнить лимит текста, сроки хранения/доступ к удалённому содержимому, permissions окончательного удаления, правило допуска после возврата и точные уведомления клиенту. В контракте право удаления описано в общем виде; матрицу полномочий по ролям Игорь должен подтвердить отдельно. Новые юридические/финансовые решения этим пакетом не принимаются.

## Экран -> Действие -> Системный результат

| Экран | Действие | Серверный результат / отказ |
| --- | --- | --- |
| Завершённая консультация / профиль | Открыть форму | Сервер проверяет владельца, завершение, оплату и отсутствие отзыва; не создаёт запись при открытии |
| Форма | Выбрать 1--5, отправить текст | Одна связанная запись; подтверждение; обновлённый публичный агрегат; кнопка повтора убрана |
| Форма | Закрыть | Нет публикации; локальный черновик не является серверным отзывом |
| Форма после timeout | Проверить результат | Получить существующий результат по консультации до повторной отправки |
| Профиль / каталог | Прочитать отзывы | Только published; одинаковые avg/count; при count=0 нейтральное состояние |
| Admin Reviews | Поиск, колонка, статус | Серверная фильтрация и пагинация разрешённых записей; пустой результат без ошибки |
| Admin Reviews | Hide / Restore / Delete | Повторная проверка права, обязательная причина, переход статуса и аудит; согласованный агрегат |
| Admin Reviews | Открыть историю | Actor/time/old/new/reason для разрешённой роли; не публичный endpoint |
| Жалоба | Создать обращение | Один связанный Support ticket; без автоматического скрытия или возврата |

## Backend Binding: Требования, Не Найденные API

Фактические Yii2 controllers, таблицы, permissions и маршруты для отзывов в этой работе не проверялись. Следующая таблица - контракт для сопоставления с существующей системой, не утверждение о наличии API. Игорь возвращает точные file/class/route/table refs перед реализацией; существующие консультации, платежи и Support не заменять новыми независимыми сущностями.

| Операция / данные | Требуемая привязка | Проверка |
| --- | --- | --- |
| Eligibility | Каноническая consultation/service_session, client/expert, состояние завершения и подтверждённая оплата | R01, R02; повторная серверная проверка при POST |
| Create/read own | Review с серверными связями, stars/text/status; UNIQUE consultation_id | R02, R03; гонка двух POST и повтор после timeout |
| Public list/aggregate | DTO без скрытых/удалённых данных и приватных идентификаторов клиента | R04, R06, R07; профиль и каталог равны |
| Moderate | Existing admin/RBAC; защищённый mutation, CSRF для cookie-auth; разрешённые переходы и reason | R05, R07; прямой запрос запрещённой роли отклоняется |
| Audit | Неизменяемая история actor/time/status/reason; аудит и изменение в одной транзакции | R05; конкурентное действие не теряет историю |
| Aggregate/cache | avg/count published; инвалидировать все публичные поверхности после commit | R04--R06; readback, не только успешный HTTP |
| Support | Existing linked-ticket operation + duplicate protection | R08; отзыв и финансовая операция не меняются |

События: review published/hidden/restored/deleted с review/expert/consultation refs для разрешённых внутренних обработчиков; публичный агрегат обновляется после commit. Канал, текст, получатели уведомления владельцу отзыва требуют подтверждения. Недоступный email/push не должен отменять успешно записанный отзыв; повторная доставка не создаёт второй отзыв. Ошибки UI: нет допуска/права; неверные stars/слишком длинный текст; уже существует; устаревший статус; недоступен сервер; неизвестный результат. Точные HTTP-коды и error DTO согласовать с действующими conventions.

Frontend: не переносить demo IDs/числа и local-state authority в production; безопасно выводить текст и причину; не разрешать HTML; серверная валидация обязательна. Разрешить loading/disabled/success/error/unknown-result состояния. Сохранить keyboard/focus возврат диалогов, адаптивность и существующие блоки. Причины модерации и скрытый текст не отдавать в публичные ответы.

## QA: Ожидаемый Результат Для Тестировщика

Локально уже проверены пять ширин 1440/1024/768/390/360, анкета с оценками и без них, допуск, первый отзыв, ошибки формы, черновик/XSS в demo, поиск/фильтры, причины и цикл модерации, аудит, реальные границы мобильного sidebar. Receipt привязан SHA256 к текущим исходникам. Это не серверная RBAC, DB, idempotency, реальные уведомления или интеграция двух экранов.

Для backend QA зафиксировать build/commit/URL, роль, обезличенные fixture refs, действие, expected/actual, PASS/FAIL/BLOCKED и доказательство. Нет сборки - `NOT_RUN`, не PASS. Выполнить R01--R09 из контракта плюс следующие проверки:

| ID | Роль и данные | Expected | Proof |
| --- | --- | --- | --- |
| B01 | Own paid completed; unpaid, foreign, incomplete; already reviewed | Только первый допустимый создаётся; прямые отрицательные запросы не меняют DB | Response + count/readback |
| B02 | Два конкурентных create; timeout/retry | Ровно одна запись и один опубликованный вклад; восстановление результата без дубля | Parallel requests + DB constraint/readback |
| B03 | Published stars 5 и 3; hide 5; restore; delete обе | 4.0/2 -> 3.0/1 -> 4.0/2 -> пусто; каталог равен профилю | Оба UI + public response после каждого шага |
| B04 | Client, foreign client, expert, moderator без delete, authorized admin | Запрещённые запросы отклонены; скрытые text/reason/client refs не утекли | Negative direct requests + public DTO |
| B05 | Два модератора со старой версией записи; пустая причина | Конфликт обработан; нет потери аудита/несогласованного агрегата; пустая причина отклонена | History + mutation/readback |
| B06 | Script/HTML payload, длинный текст, stars 0/6/fraction | Код не исполняется; невалидные данные отклонены сервером | UI screenshot + validation response |
| B07 | Двойная жалоба; сбой уведомления | Один linked ticket; без изменения денег/рейтинга; сохранённый отзыв не потерян | Ticket readback + event processing |
| B08 | 1440/1024/768/390/360; keyboard; reload | Блоки/фото сохранены; нет overflow/overlap; focus корректен; серверные данные сохраняются | Screenshots + scenario receipt |

**Done продукта:** точные backend refs, согласованные открытые правила, тестовая сборка, R01--R09/B01--B08 с фактическими proof, QA без критических дефектов и PM/Заказчик acceptance. До этого карточка не переводится в Done.
